Create one controller for the calendar and any controls that live beside it. Pass it to `EventCalendar` as `calendar` and to standalone calendar controls as `calendar`. Parts inside the root can read it from context.

```tsx
const calendar = useEventCalendar({
  load: loadTeamEvents,
  timeZone: "Europe/Lisbon",
  onEventChange: saveChange,
})

return (
  <EventCalendar calendar={calendar}>
    <EventCalendarHeader>
      <EventCalendarTitle />
      <EventCalendarNavigation />
    </EventCalendarHeader>
    <EventCalendarContent />
  </EventCalendar>
)
```

Use a stable loader and forward its `signal`. Return events that overlap the requested range, including events that begin earlier and end inside it. Save the edits from `onEventChange` and return the promise so the controller can track pending changes and recover from a failed save.

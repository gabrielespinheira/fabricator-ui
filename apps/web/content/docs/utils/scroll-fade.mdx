## Installation

If your project was set up with `npx fabricator-ui@latest init`, you already have `scroll-fade`. The base utilities ship with the `shadcn` package, which the CLI imports in your global CSS file, and the Fabricator UI foundations, installed with every Fabricator component, redraw them on the eased curve and add `scroll-fade-inset-*` and `sticky-fade-*`.

Otherwise, install the package:

```bash
npm install shadcn
```

Then import the shared utilities in your global CSS file:

```css
@import "tailwindcss";
@import "shadcn/tailwind.css";
```

## Usage

| Class                             | Styles                                                                                                                    |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `scroll-fade`                     | `mask-image: var(--scroll-fade-mask, var(--scroll-fade-block));` <br /> `animation-timeline: scroll(self y);`             |
| `scroll-fade-y`                   | `mask-image: var(--scroll-fade-mask, var(--scroll-fade-block));` <br /> `animation-timeline: scroll(self y);`             |
| `scroll-fade-x`                   | `mask-image: var(--scroll-fade-mask, var(--scroll-fade-inline));` <br /> `animation-timeline: scroll(self inline);`       |
| `scroll-fade-t`                   | Fade mask on the top edge. <br /> `animation-timeline: scroll(self y);`                                                   |
| `scroll-fade-b`                   | Fade mask on the bottom edge. <br /> `animation-timeline: scroll(self y);`                                                |
| `scroll-fade-l`                   | Fade mask on the left edge. <br /> `animation-timeline: scroll(self x);`                                                  |
| `scroll-fade-r`                   | Fade mask on the right edge. <br /> `animation-timeline: scroll(self x);`                                                 |
| `scroll-fade-s`                   | Fade mask on the start edge. <br /> `animation-timeline: scroll(self inline);`                                            |
| `scroll-fade-e`                   | Fade mask on the end edge. <br /> `animation-timeline: scroll(self inline);`                                              |
| `scroll-fade-<number>`            | `--scroll-fade-size: calc(var(--spacing) * <number>);`                                                                    |
| `scroll-fade-[<value>]`           | `--scroll-fade-size: <value>;`                                                                                            |
| `scroll-fade-{t,b,s,e}-<number>`  | `--scroll-fade-{t,b,s,e}-size: calc(var(--spacing) * <number>);`                                                          |
| `scroll-fade-{t,b,s,e}-[<value>]` | `--scroll-fade-{t,b,s,e}-size: <value>;`                                                                                  |
| `scroll-fade-none`                | `--scroll-fade-mask: none;`                                                                                               |
| `scroll-fade-inset-{t,b,s,e}-<n>` | `--scroll-fade-{t,b,s,e}-inset: calc(var(--spacing) * <n>);` Starts that edge's fade past a sticky region.                |
| `sticky-fade-{t,b,s,e}`           | On a sticky or fixed element: fades its own background past that edge while content scrolls under it.                     |
| `surface-fade-{t,b,s,e}`          | Paints `--surface-fade-color` as the element's background, solid at that edge, eased to clear over `--surface-fade-size`. |

Add `scroll-fade` or `scroll-fade-y` to the scroll container, i.e. the element that has `overflow-y-auto`.

```tsx
<div className="scroll-fade overflow-y-auto">{/* ... */}</div>
```

The fade is scroll-aware and tracks the scroll position:

- At rest, the top edge is crisp and the bottom edge fades to hint at more content.
- As you scroll, a fade appears at the top and both edges stay faded mid-scroll.
- At the end, the bottom edge sharpens to show you have reached the last item.

The fade is applied with `mask-image`, so it dissolves the content itself rather than overlaying a color, and adapts to any background without configuration. Fabricator UI draws the mask on an eased curve that is flat at both ends, so there is no line where the fade starts or where the content turns solid, and it strengthens in place as you scroll instead of growing from a hard edge. If your scroll area sits inside a card, put the background and border on a wrapper and `scroll-fade` on the inner scroller, so the fade dissolves the content and not the card. The mask also clips the scroller's own focus outline, so a focusable scroller draws its focus ring on that wrapper.

The [`ScrollArea`](/docs/components/scroll-area) and [`MessageScroller`](/docs/components/message-scroller) components can use `scroll-fade` on their scrollable viewport.

## No Overflow, No Fade

If the content does not overflow, no fade is shown. You can apply `scroll-fade` to any list without checking whether it scrolls.

## Edge Fades

Use edge utilities when only one edge should track the scroll position.

<ComponentPreview
  styleName="base-rhea"
  name="scroll-fade-edge"
  previewClassName="h-auto"
/>

```tsx
<div className="scroll-fade-b overflow-y-auto">{/* ... */}</div>
```

The edge utilities are scroll-aware. Start edges fade in after you scroll away from the start, and end edges fade out when you reach the end. Use `scroll-fade-t`, `scroll-fade-b`, `scroll-fade-l`, and `scroll-fade-r` for physical edges. Use `scroll-fade-s` and `scroll-fade-e` for the logical start and end edges.

## Fade Size

The fade depth defaults to `16%` of the container, capped at `56px` so tall scrollers stay subtle. Use `scroll-fade-<number>` to set a fixed size on the spacing scale instead, the same way `scroll-mt-<number>` works.

<ComponentPreview
  styleName="base-rhea"
  name="scroll-fade-size"
  previewClassName="h-auto"
/>

```tsx
<div className="scroll-fade overflow-y-auto scroll-fade-24">{/* ... */}</div>
```

For one-off values, use an arbitrary length or percentage:

```tsx
<div className="scroll-fade overflow-y-auto scroll-fade-[15%]">{/* ... */}</div>
```

To fade opposite edges by different amounts, use the per-edge modifiers `scroll-fade-t-<number>`, `scroll-fade-b-<number>`, `scroll-fade-s-<number>`, and `scroll-fade-e-<number>`. They override `scroll-fade-<number>` on the edge they target and accept arbitrary values too.

```tsx
<div className="scroll-fade overflow-y-auto scroll-fade-b-8 scroll-fade-t-2">
  {/* ... */}
</div>
```

Use the logical `s`/`e` modifiers for the start and end edges of horizontal scrollers.

The fade strengthens over a fixed scroll distance rather than appearing instantly. That distance is the `--scroll-fade-reveal` variable, `64px` by default and independent of the fade depth. Lower it for a snappier reveal or raise it for a more gradual one:

```tsx
<div className="scroll-fade overflow-y-auto [--scroll-fade-reveal:64px]">
  {/* ... */}
</div>
```

## Sticky Headers and Footers

A sticky header or footer inside a scroller should not cut the content at a line. Give the scroller an inset on that edge, the height of the sticky part, so the sticky part stays solid and the content fades as it reaches it.

<ComponentPreview
  styleName="base-rhea"
  name="scroll-fade-sticky"
  previewClassName="h-auto"
/>

```tsx
<div className="scroll-fade overflow-y-auto scroll-fade-inset-b-12 scroll-fade-inset-t-10">
  <header className="sticky top-0 h-10 bg-background">{/* ... */}</header>
  {/* ... */}
  <footer className="sticky bottom-0 h-12 bg-background">{/* ... */}</footer>
</div>
```

Use `scroll-fade-inset-t-<number>` and `scroll-fade-inset-b-<number>` for headers and footers, and `scroll-fade-inset-s-<number>` and `scroll-fade-inset-e-<number>` for pinned columns. They take arbitrary values too, such as `scroll-fade-inset-t-[var(--header-height)]`.

A mask can only dissolve the scroller it is on. When the content scrolls under a fixed header on the page itself, or the scroller can't be masked, put `sticky-fade-b` on the header instead (`sticky-fade-t` on a footer or composer, `sticky-fade-e` on a column pinned to the start). It paints past that edge on the same eased curve, and only while content is scrolled under it. Change the depth with `--sticky-fade-size` (`40px` by default):

```tsx
<header className="sticky-fade-b sticky top-0 bg-card">{/* ... */}</header>
```

`sticky-fade-*` draws with the element's `::after`, so the element must be sticky, fixed or otherwise positioned, and must not use `::after` itself.

## Surface Colors

A painted fade has to be the colour of the surface under it, or it reads as a dark or light band. `sticky-fade-*` fades the sticky element's own background colour, so a header on a card fades to the card and one in a popover to the popover, with nothing to configure. Give the sticky element its surface, which it needs anyway to hide what scrolls under it.

`surface-fade-t`, `surface-fade-b`, `surface-fade-s` and `surface-fade-e` paint the same fade as an element's own background: `--surface-fade-color` (the page by default), solid at the named edge, eased to clear over the last `--surface-fade-size`. `--surface-fade-wash` paints a translucent wash on top, such as a row's hover or selection, so a lit row stays lit as it fades. A pinned cell uses it to let the rows scrolling under it show through its far padding. It is painted rather than masked, so it stays cheap on every row of a long list. The [Data Table](/docs/components/base/data-table)'s pinned columns work this way:

```tsx
<td className="sticky start-0 surface-fade-s [--surface-fade-color:var(--card)] [--surface-fade-size:--spacing(3)] [--surface-fade-wash:var(--row-wash)]">
  {/* ... */}
</td>
```

## Disabling the Fade

Use `scroll-fade-none` to remove the fade. It works in any class order, so the typical use is responsive or stateful:

```tsx
<div className="scroll-fade overflow-y-auto md:scroll-fade-none">
  {/* ... */}
</div>
```

## Fallback

The scroll-aware behavior is implemented with [CSS scroll-driven animations](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_scroll-driven_animations), with no JavaScript and no scroll listeners. In browsers that do not support scroll-driven animations, `scroll-fade` falls back to a static fade on both edges, edge utilities fall back to a static fade on the selected edge, and `sticky-fade-*` always shows.

Since the mask is applied to the scroll container itself, a visible scrollbar fades with the content at the edges. Pair `scroll-fade` with `no-scrollbar`, which ships in the same package, if you want to hide the scrollbar entirely.

Fabricator Icons is the icon set of Fabricator UI:

- **Outline icons.** All 2,015 [Lucide](https://lucide.dev) icons, from Lucide 1.66.0, with Lucide's names and the same shapes. Code written for `lucide-react` moves over by changing the import path.
- **Custom icons.** Fabricator's own icons, drawn to the same rules so they sit beside Lucide's. Find them under the Custom category on the [Icons](/icons) page.
- **Brand marks.** 143 logos, from social networks to developer tools, drawn as their owners publish them. They render in one colour, or in the brand's own colours with `color="brand"`. See [Brands](/docs/icons/brands).
- **Animated icons.** 447 Lucide icons that animate on hover, with the same names and props as the outline icons, for the web. See [Animated](/docs/icons/animated).
- **Duotone.** A translucent second layer for outline icons. The packages render it today; the first duotone icons are still being drawn.

Search, preview and copy every icon on the [Icons](/icons) page.

## In Fabricator UI components

A new project uses Fabricator Icons: `init` and the [Get started](/create) page install this package, and every component you add imports from it. To keep Lucide or use another pack, pick it in the Icons setting on Get started, which adds it to the command:

```bash
npx fabricator-ui@latest init -p "https://fabricator-ui.vercel.app/init?iconLibrary=lucide"
```

An existing project keeps the icons it has. To move one over, set its registry entry in `components.json`, then add its components again with `--overwrite`:

```json title="components.json"
{
  "registries": {
    "@fabricator": {
      "url": "https://fabricator-ui.vercel.app/r/fabricator/{style}/{name}.json",
      "params": { "icons": "fabricator" }
    }
  }
}
```

`iconLibrary` stays `lucide` in both cases, because the shadcn CLI only knows its five libraries. The outline icons have Lucide's names and shapes, so nothing changes on screen.

## Packages

| Package                                                         | For                                                                                    |
| --------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| [`@fabricator-ui/icons`](/docs/icons/react)                     | React: web apps, and the renderers of Electron and Tauri apps                          |
| [`@fabricator-ui/icons-react-native`](/docs/icons/react-native) | React Native and Expo                                                                  |
| [`@fabricator-ui/icons-static`](/docs/icons/static)             | SVG files, sprites, JSON and SVG strings for any framework, and PNGs for desktop trays |

All three are built from the same sources, so an icon looks the same on every platform.

## Quick start

```bash
npm install @fabricator-ui/icons
```

```tsx
import { BellIcon, HouseIcon } from "@fabricator-ui/icons"
import { GithubIcon } from "@fabricator-ui/icons/brands"

export function Toolbar() {
  return (
    <nav className="flex items-center gap-3">
      <HouseIcon className="size-4" />
      <BellIcon className="size-4" />
      <GithubIcon className="size-4" />
    </nav>
  )
}
```

## Moving from lucide-react

Every icon keeps its Lucide name, its `Icon`-suffixed form and Lucide's aliases, and takes Lucide's props, so moving is an import change. Replace `lucide-react` with `@fabricator-ui/icons`:

```tsx
import { HouseIcon, Settings } from "@fabricator-ui/icons"
```

Three things differ:

- There is no `LucideProvider`. Set sizes and strokes with props or CSS; without a context, icons stay server components.
- The `Lucide`-prefixed names (`LucideHouse`) aren't exported.
- Icons carry the classes `fab-icon fab-icon-<name>` instead of `lucide lucide-<name>`.

## Icons in Fabricator UI components

Components from the registry draw their icons with the icon library in your `components.json` (`iconLibrary`), Lucide by default. The outline set is Lucide's, so those icons and `@fabricator-ui/icons` look identical side by side. Fabricator components draw icons at 14, 16 or 18px, following the [density](/docs/foundations/density), with a 1.5 stroke that turns 2 on hover.

## How the icons are drawn

The outline icons follow Lucide's [design rules](https://lucide.dev/contribute/icons/specification): a 24 × 24 canvas, 2px strokes with round caps and joins, at least 1px from the edge, and at least 2px between shapes. Icons Fabricator adds are drawn to the same rules, reviewed at 14 to 24px and stroke 1.5 and 2, and checked by a script before they ship.

Brand marks keep their owners' shapes. The only change is a uniform scale, so a mark that reaches the corners of its box doesn't look larger than its neighbours.

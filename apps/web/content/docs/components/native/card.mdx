title: Card
description: One discrete thing on a surface, such as a metric, a chart, a record or a plan, with a header, its value and a footer.

component: true
---

<NativePreview src="/images/native/card.jpg" alt="Card on iOS" />

## Installation

```bash
npx fabricator-ui@latest add card
```

## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardLink,
  CardMedia,
  CardTitle,
  CardValue,
  CardValueCaption,
} from "@/components/ui/card"
import { Delta } from "@/components/ui/delta"
import { Text } from "@/components/ui/text"
```

```tsx
<Card className="w-full">
  <CardHeader>
    <CardTitle>Money in</CardTitle>
    <CardAction>
      <Delta change={11.5} />
    </CardAction>
  </CardHeader>
  <CardContent className="gap-(--density-6)">
    <CardValue>$981K</CardValue>
    <CardValueCaption>from $879.5K</CardValueCaption>
  </CardContent>
</Card>
```

## Composition

## API reference

| Prop | Values |
| --- | --- |
| `variant` | `default`, `icon`, `image`, `muted`, `tray` |

Props it adds to what it wraps: `onPress`, `size`.

## Differences from web

**Same.** It works as it does on the web, with `onPress` for `onClick`.

## Accessibility

Parts set `role="heading"`, `role="link"`, read by VoiceOver and TalkBack. Give a control with no text an `accessibilityLabel`.

## Installation

```bash
npx fabricator-ui@latest add card
```

## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"
import { Text } from "@/components/ui/text"
```

```tsx
<Card className="w-full">
  <CardHeader>
    <CardTitle>Project status</CardTitle>
    <CardDescription>Everything in this release.</CardDescription>
  </CardHeader>
  <CardContent>
    <Text>Twelve tasks are done and three are in review.</Text>
  </CardContent>
  <CardFooter>
    <Button size="sm">Open</Button>
    <Button size="sm" variant="ghost">
      Dismiss
    </Button>
  </CardFooter>
</Card>
```

## Composition

- `Card`
- `CardAction`
- `CardContent`
- `CardDescription`
- `CardFooter`
- `CardHeader`
- `CardTitle`

## API reference



Props it adds to what it wraps: `size`.

## Differences from web

**Same.** It works as it does on the web, with `onPress` for `onClick`.

## Accessibility

Parts set `role="heading"`, read by VoiceOver and TalkBack. Give a control with no text an `accessibilityLabel`.

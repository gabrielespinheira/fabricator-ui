title: Audio Player
description: An audio file on a card with its waveform, skip, speed and volume, a cover variant for music and a compact one for voice messages.
base: native
component: true
---

## Installation

```bash
npx fabricator-ui@latest add audio-player
```

## Usage

```tsx
import { AudioPlayer } from "@/components/ui/audio-player"
import { Text } from "@/components/ui/text"
```

```tsx
<AudioPlayer
  src={`${MEDIA}/sintel-trailer.m4a`}
  artwork={`${MEDIA}/sintel-trailer-cover.jpg`}
  title="Sintel, trailer"
  artist="Blender Foundation"
  peaks={PEAKS}
  onPlayingChange={setIsPlaying}
  className="w-full"
/>
<Text className="text-(length:--density-text-12) text-muted-foreground">
  {isPlaying ? "Playing" : "Paused"} · Sintel © Blender Foundation, CC
  BY 3.0
</Text>
```

## Differences from web

**New engine.** expo-audio plays the file in place of the browser's `<audio>`. The seek bar is dragged or tapped, and shows the time under the finger while dragged; it has no hover preview and doesn't show what has loaded. There's no volume slider: the device's buttons set the volume, and mute stays. The play glyphs fade and scale without the blur. There are no keyboard shortcuts.

## Accessibility

Parts set `role="alert"`, `role="button"`, read by VoiceOver and TalkBack. Give a control with no text an `accessibilityLabel`.

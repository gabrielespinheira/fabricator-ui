## Installation

```bash
npx fabricator-ui@latest add sidebar
```


## API reference

| Prop | Values |
| --- | --- |
| `variant` | `default`, `outline` |
| `size` | `default`, `lg`, `md`, `sm` |
| `state` | `active`, `default` |

Props it adds to what it wraps: `"data-dragging"`, `bordered`, `collapsible`, `defaultOpen`, `dot`, `gutter`, `icon`, `isActive`, `isFlushTop`, `isMobile`, `mobileSidebar`, `onGapWidthChange`, `onLayout`, `onOpenChange`, `onPress`, `onWidthChange`, `open`, `peek`, `persist`, `shortcut`, `showIcon`, `showOnHover`, `side`, `size`, `status`, `statusBarHeight`, `tooltip`, `variant`, `width`, `widthMobile`.

## Differences from web

**Touch input.** On phones it reveals behind the page, following the finger, or slides over it from an edge swipe. `SidebarRail` toggles on a tap instead of resizing, and row actions always show. `persist`, `shortcut`, `peek` and `onWidthChange` are accepted and do nothing.

## Accessibility

Parts set `role="button"`, `role="dialog"`, `role="heading"`, `role="list"`, `role="listitem"`, read by VoiceOver and TalkBack. Give a control with no text an `accessibilityLabel`.

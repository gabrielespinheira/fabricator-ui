## Installation

```bash
npx fabricator-ui@latest add bot-face
```

## Usage

```tsx
import {
  BotFace,
  type BotFaceColor,
  type BotFaceEyes,
  type BotFaceShape,
  type BotFaceState,
} from "@/components/ui/bot-face"
import { Button } from "@/components/ui/button"
import { ColorPickerPopover } from "@/components/ui/color-picker"
```

```tsx
<BotFace
  state={state}
  shape={shape}
  size="lg"
  eyes={eyes}
  color={color}
  aria-label={`Assistant ${state.replaceAll("-", " ")}`}
/>
<View className="flex-row flex-wrap justify-center gap-2">
  {(
    [
      "idle",
      "listening",
      "thinking",
      "working",
      "speaking",
      "happy",
      "sad",
      "questioning",
      "awaiting-permission",
      "error",
    ] as const
  ).map((value) => (
    <Button
      key={value}
      variant={state === value ? "secondary" : "ghost"}
      aria-pressed={state === value}
      onPress={() => setState(value)}
    >
      <BotFace
        state={value}
        color={color}
        eyes={eyes}
        size="sm"
        animated={false}
      />
      {value === "awaiting-permission"
        ? "Permission"
        : value.charAt(0).toUpperCase() + value.slice(1)}
    </Button>
  ))}
</View>
<View className="flex-row flex-wrap justify-center gap-2">
  {shapes.map((value) => (
    <Button
      key={value}
      variant={shape === value ? "secondary" : "ghost"}
      aria-label={`Use ${value} shape`}
      aria-pressed={shape === value}
      onPress={() => setShape(value)}
    >
      <BotFace shape={value} color={color} eyes={eyes} size="sm" />
    </Button>
  ))}
</View>
<View className="flex-row flex-wrap justify-center gap-2">
  {paletteColors.map((value) => (
    <Button
      key={value}
      variant={color === value ? "secondary" : "ghost"}
      aria-label={`Use ${value} color`}
      aria-pressed={color === value}
      onPress={() => setColor(value)}
    >
      <BotFace
        shape="circle"
        color={value}
        eyes="dots"
        size="sm"
        animated={false}
        style={{ width: 24, height: 24 }}
      />
    </Button>
  ))}
</View>
<ColorPickerPopover
  triggerLabel="Custom"
  value={customColor}
  onOpenChange={(isOpen) => {
    if (isOpen) setColor(customColor)
  }}
  onValueChange={(_, parsed) => {
    const next = `#${parsed.hex.slice(1)}` as const
    setCustomColor(next)
    setColor(next)
  }}
/>
<View className="flex-row flex-wrap justify-center gap-2">
  {(["slant", "dots", "square"] as const).map((value) => (
    <Button
      key={value}
      variant={eyes === value ? "secondary" : "outline"}
      aria-pressed={eyes === value}
      onPress={() => setEyes(value)}
    >
      {value === "slant"
        ? "Slanted"
        : value === "dots"
          ? "Dots"
          : "Squares"}
    </Button>
  ))}
</View>
```

## Differences from web

**Touch input.** The same ten `state` expressions, geometry and `useBotFaceState` session hook run on native. Idle gaze follows touches on the face rather than a window pointer. Reanimated retains the pose and blink phase across state changes and pauses when the app is inactive. Reduce Motion, motion-off, instant and `animated={false}` keep the selected expression still. See the web BotFace page for the state and normalized session API; use visible status text and real approval controls alongside the face.

## Accessibility

Text is read as it appears. Give a control with no text an `accessibilityLabel`.

## Installation

```bash
npx fabricator-ui@latest add video-player
```

## Usage

```tsx
import { Text } from "@/components/ui/text"
import { VideoPlayer } from "@/components/ui/video-player"
```

```tsx
<VideoPlayer
  src="https://fabricator-ui.vercel.app/media/sintel-trailer.mp4"
  poster="https://fabricator-ui.vercel.app/media/sintel-trailer.jpg"
  title="Sintel, trailer"
  chapters={[
    { start: 0, title: "The mountains" },
    { start: 10, title: "The gatekeeper" },
    { start: 24, title: "The dragon" },
    { start: 35, title: "The quest" },
    { start: 46, title: "Credits" },
  ]}
  tracks={[
    {
      src: "https://fabricator-ui.vercel.app/media/sintel-trailer.en.vtt",
      srcLang: "en",
      label: "English",
    },
    {
      src: "https://fabricator-ui.vercel.app/media/sintel-trailer.pt.vtt",
      srcLang: "pt-BR",
      label: "Português",
    },
  ]}
  onPlayingChange={setIsPlaying}
  className="w-full"
/>
<Text className="text-(length:--density-text-12) text-muted-foreground">
  {isPlaying ? "Playing" : "Paused"} · Sintel © Blender Foundation, CC
  BY 3.0
</Text>
```

## Differences from web

**New engine.** expo-video plays the video in place of the browser's `<video>`. A tap shows or hides the controls and a double tap plays or pauses. Captions are read from the same WebVTT files and drawn by the player. Settings open as a bottom sheet in the theme's colours, full screen is the system's player with its own controls, and there's no volume slider: the device's buttons set the volume. There are no keyboard shortcuts.

## Accessibility

Parts set `role="alert"`, `role="button"`, `role="menu"`, `role="radio"`, `role="separator"`, read by VoiceOver and TalkBack. Give a control with no text an `accessibilityLabel`.

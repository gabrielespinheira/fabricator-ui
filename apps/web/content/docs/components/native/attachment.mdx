<NativePreview src="/images/native/attachment.jpg" alt="Attachment on iOS" />

## Installation

```bash
npx fabricator-ui@latest add attachment
```

## Usage

```tsx
import {
  Attachment,
  AttachmentAction,
  AttachmentActions,
  AttachmentContent,
  AttachmentDescription,
  AttachmentGroup,
  AttachmentMedia,
  AttachmentTitle,
  AttachmentTrigger,
} from "@/components/ui/attachment"
import { Spinner } from "@/components/ui/spinner"
import { Text } from "@/components/ui/text"
```

```tsx
<Attachment state="idle" className="w-full">
  <AttachmentMedia>
    <ClockIcon />
  </AttachmentMedia>
  <AttachmentContent>
    <AttachmentTitle>selected-file.pdf</AttachmentTitle>
    <AttachmentDescription>Ready to upload</AttachmentDescription>

  <AttachmentMedia>

            </AttachmentAction>
          </AttachmentActions>

            <FileTextIcon />
          </AttachmentMedia>

            <AttachmentTitle>market-research.pdf</AttachmentTitle>

        <Attachment state="error" className="w-full">

          </AttachmentActions>
```

## API reference

| Prop | Values |
| --- | --- |
| `size` | `default`, `sm`, `xs` |
| `orientation` | `horizontal`, `vertical` |
| `variant` | `icon`, `image` |
| `state` | `done`, `error`, `idle`, `processing`, `uploading` |

Props it adds to what it wraps: `state`.

## Differences from web

**Same.** It works as it does on the web, with `onPress` for `onClick`.

## Accessibility

Text is read as it appears. Give a control with no text an `accessibilityLabel`.

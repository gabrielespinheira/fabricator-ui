---
title: Preview Rail
description: A rail of thin ticks, one per section, that swell around the pointer with a card naming the section it's on.
base: native
component: true
---

## Installation

```bash
npx fabricator-ui@latest add preview-rail
```

## Usage

```tsx
import {
  PreviewRail,
  type PreviewRailItem,
} from "@/components/ui/preview-rail"
import { Text } from "@/components/ui/text"
```

```tsx
<PreviewRail
  items={SECTIONS}
  defaultValue="components"
  aria-label="Documentation"
/>
```

## Composition

- `PreviewRail`
- `PreviewRailItem`
- `PreviewRailProps`

## Differences from web

**Touch input.** A finger scrubs the rail: a press lights the tick under it and shows its card, a drag moves the light with a tick on each step, and lifting on the rail chooses the lit item. An `href` with a scheme opens through `Linking`; in-page anchors and paths have nowhere to go in an app, so navigate from `onValueChange`. Screen readers activate a tick with a double tap and hear its description as a hint. There's no hover or keyboard.

## Accessibility

Parts set `role="navigation"`, read by VoiceOver and TalkBack. Give a control with no text an `accessibilityLabel`.

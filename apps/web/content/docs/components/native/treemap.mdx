---
title: Treemap
description: Hierarchical parts of a whole, as cells sized by value and coloured by their top-level group.
base: native
component: true
---

## Installation

```bash
npx fabricator-ui@latest add treemap
```

## Usage

```tsx
import { Button } from "@/components/ui/button"
import { Treemap } from "@/components/ui/treemap"
```

```tsx
<Treemap
  data={QUARTERS.Q1}
  label="Portfolio allocation"
  formatValue={currency}
  className="h-72 w-full"
/>
```

## Composition

- `Treemap`
- `TreemapProps`

## Accessibility

Text is read as it appears. Give a control with no text an `accessibilityLabel`.

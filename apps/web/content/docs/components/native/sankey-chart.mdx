---
title: Sankey Chart
description: Flow volumes between stages, from sources to destinations, as ribbons as thick as each flow.
base: native
component: true
---

## Installation

```bash
npx fabricator-ui@latest add sankey-chart
```

## Usage

```tsx
import { Button } from "@/components/ui/button"
import { SankeyChart } from "@/components/ui/sankey-chart"
```

```tsx
<SankeyChart
  nodes={nodes}
  links={QUARTERS.Q2}
  label="Revenue by channel, product and region"
  formatValue={currency}
  className="h-80 w-full"
/>
```

## Composition

- `SankeyChart`
- `SankeyChartProps`

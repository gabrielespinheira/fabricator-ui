---
title: Button Group
description: A container that groups related buttons together with consistent styling.
base: native
component: true
---

## Installation

```bash
npx fabricator-ui@latest add button-group
```

## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  ButtonGroup,
  ButtonGroupSeparator,
  ButtonGroupText,
} from "@/components/ui/button-group"
import { Input } from "@/components/ui/input"
```

```tsx
<ButtonGroup orientation="horizontal">
  <Button variant="outline">Archive</Button>
  <Button variant="outline">Report</Button>
  <Button variant="outline">Snooze</Button>
</ButtonGroup>
```

## Composition

- `ButtonGroup`
- `ButtonGroupSeparator`
- `ButtonGroupText`

## API reference

| Prop          | Values                   |
| ------------- | ------------------------ |
| `orientation` | `horizontal`, `vertical` |

## Differences from web

**Same.** It works as it does on the web, with `onPress` for `onClick`.

## Accessibility

Parts set `role="group"`, read by VoiceOver and TalkBack. Give a control with no text an `accessibilityLabel`.

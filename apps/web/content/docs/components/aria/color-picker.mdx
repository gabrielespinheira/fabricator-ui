Drag in the area to set saturation and brightness, and use the sliders for hue and alpha (transparency); each shows its value beside it. Pick a format to type or scrub its channels: drag a field's letter sideways to change its value. Use it inline as a panel, or behind a trigger with `ColorPickerPopover`.

Color Picker is part of the Fabricator style. It's composed from [Slider](/docs/components/aria/slider), [Select](/docs/components/aria/select), [Input Group](/docs/components/aria/input-group), [Popover](/docs/components/aria/popover) and [Tooltip](/docs/components/aria/tooltip), so every control looks and behaves like the rest of your fields. It's adapted from the Color Picker of [Fluid Functionalism](https://www.fluidfunctionalism.com/docs/color-picker) (MIT).

## Composition

```text
ColorPicker
├── area (saturation and brightness)
├── hue and alpha sliders, each with its value
├── one row: format select, channel fields, eyedropper
└── swatches (optional)

ColorPickerPopover
├── trigger (tile, hex value, label) and optional remove button
└── ColorPicker, in a popover
```

`ColorSwatch` and `ColorTile` are exported too, to show a color elsewhere with the same checker behind translucent colors.

## What it reads

`value`, `defaultValue` and the hex field read:

- hex with 3, 4, 6 or 8 digits, with or without `#`
- `rgb()` and `rgba()`, with commas, spaces or a `/` before alpha
- `hsl()` and `hsla()`
- `oklch()`, with lightness as a percent or a fraction

The hex field and swatches also take named colors (`tomato`). A value that can't be read is ignored and the color stays as it was.

### ColorPicker

Every `div` prop, plus:

| Prop             | Type                                              | Default     |
| ---------------- | ------------------------------------------------- | ----------- |
| `value`          | `string`                                          | -           |
| `defaultValue`   | `string`                                          | `"#6b97ff"` |
| `onValueChange`  | `(value: string, color: ParsedColor) => void`     | -           |

## Accessibility

- The area is a slider named "Color" that reports saturation and brightness as its value text. Left and right arrows change saturation, up and down brightness, by 1% (10% with Shift). Home and End jump to the saturation ends, Page Up and Page Down to the brightness ends.
- The hue and alpha sliders are Sliders, named "Hue" and "Alpha", with the Slider's keyboard. The alpha slider is the only alpha control, in percent. The value beside each slider is hidden from screen readers, which hear it from the slider.
- Each channel field is a text input named after its channel. Up and down arrows step it (ten times further with Shift), Enter or leaving the field commits typed text, and Escape puts the last value back. Hue fields wrap past 360.
- Swatches are toggle buttons: the selected one reports `aria-pressed`, and a labelled swatch is named by its label.
- The popover's trigger is a button that reports `aria-expanded`. Focus moves into the panel when it opens and back to the trigger when it closes. With a changed value in a field, the first Escape reverts the field and the second closes the popover.
- The eyedropper is a button named "Pick a color from the screen". Pressing Escape during a pick cancels it.

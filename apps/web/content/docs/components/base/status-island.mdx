A status island is one floating pill for whatever is live right now: a timer, a call, an upload, a saved note. When what it shows changes, it reshapes around the new content instead of swapping boxes: the width lands first and the height drops into place, while the new content fades in through a blur.

Status Island is part of the Fabricator style. It's built on HTML, so the same component ships for every base.

## Usage

```tsx
import {
  StatusIsland,
  StatusIslandContent,
} from "@/components/ui/status-island"
```

```tsx
<StatusIsland>
  <StatusIslandContent key={state}>
    <UploadIcon />
    Uploading launch-deck.pdf, 64%
  </StatusIslandContent>
</StatusIsland>
```

## Composition

```text
StatusIsland             data-slot="status-island" role="status" [data-measured]
└── div                  data-slot="status-island-frame"
    └── StatusIslandContent data-slot="status-island-content"
```

Give each state its own `key` on `StatusIslandContent` so the new content fades in. The island measures its content, so anything inside sets its size.

## Motion

The island takes its content's size: width on the lead spring and height on the soft spring, so a change lands sideways first and then drops. Its corners stay a full pill while it is short and stop at a card's radius when tall. New content fades in out of a small blur on the fade spring. Reduce Motion keeps the fade and resizes at once.

## API Reference

`StatusIsland` and `StatusIslandContent` render a `div` and take its props.

## Accessibility

The island is a status region, so screen readers announce what it changes to, politely, without moving focus. Keep its text short, and put anything the person can act on (a button to end the call) inside it as a normal control.

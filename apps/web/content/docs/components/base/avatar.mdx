## Usage

```tsx showLineNumbers
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
```

```tsx showLineNumbers
<Avatar>
  <AvatarImage src="https://github.com/gabrielespinheira.png" />
  <AvatarFallback>CN</AvatarFallback>
</Avatar>
```

## Composition

Use the following composition to build an `Avatar`:

```text
Avatar
├── AvatarImage
├── AvatarFallback
└── AvatarBadge
```

Use the following composition to build an `AvatarGroup`:

```text
AvatarGroup
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
└── AvatarGroupCount
```

```tsx showLineNumbers

  <AvatarImage
    src="https://github.com/gabrielespinheira.png"

  <AvatarBadge className="bg-green-600 dark:bg-green-800" />

```

## Avatar Group with Tooltips

Pass `tooltip` to name each person on hover and keyboard focus. The group parts around the avatar under the pointer: it lifts and comes forward while its neighbours slide aside, on a spring. Moving along the group swaps names without replaying the tooltip's entrance.

<ComponentPreview styleName="base-nova" name="avatar-group-tooltip" />

```tsx showLineNumbers
<AvatarGroup>
  <Avatar tooltip="Gabriel Espinheira">
    <AvatarImage src="https://github.com/gabrielespinheira.png" alt="" />
    <AvatarFallback>GE</AvatarFallback>
  </Avatar>
  <AvatarGroupCount>+3</AvatarGroupCount>
</AvatarGroup>
```

## API Reference

### Avatar

The `Avatar` component is the root component that wraps the avatar image and fallback.

| Prop        | Type                            | Default     |
| ----------- | ------------------------------- | ----------- |
| `size`      | `"default" \| "sm" \| "lg"`     | `"default"` |
| `tooltip`   | `string \| TooltipContentProps` | -           |
| `className` | `string`                        | -           |

A string is the tooltip's text; an object is passed to the tooltip's content, for its `side`, `className` or richer `children`. An avatar with a tooltip takes focus and becomes an image named by a string tooltip; pass `aria-label` when its content isn't a string.

### AvatarImage

The `AvatarImage` component displays the avatar image. It accepts all Base UI Avatar Image props.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `src`       | `string` | -       |
| `alt`       | `string` | -       |
| `className` | `string` | -       |

### AvatarFallback

The `AvatarFallback` component displays a fallback when the image fails to load. It accepts all Base UI Avatar Fallback props.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarBadge

The `AvatarBadge` component displays a badge indicator on the avatar, typically positioned at the bottom right.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarGroup

The `AvatarGroup` component displays a group of avatars with overlapping styling.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarGroupCount

The `AvatarGroupCount` component displays a count indicator in an avatar group, typically showing the number of additional avatars.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

## Accessibility

- An avatar's image takes its `alt`; with an image that fails, the fallback's initials show instead.
- With a `tooltip`, the avatar is in the tab order with `role="img"`, named by the tooltip's text, which also shows on focus.
- The group's parting runs for a fine pointer and keyboard focus only, and reduced motion keeps the avatar coming forward without the moves.

For more information about Base UI Avatar props, see the [Base UI documentation](https://base-ui.com/react/components/avatar#api-reference).

Drag the thumb along the track: it follows your finger, gives like rubber past either end, and confirms once it has gone most of the way. Short of that it springs back. The ink behind it fills as it travels and the label fades. Use it on touch screens for an action a stray tap shouldn't set off, such as sending a payment or ending a call.

Slide to Confirm is part of the Fabricator style. It's built on HTML, so the same component ships for every base.

## Usage

```tsx
import { SlideToConfirm } from "@/components/ui/slide-to-confirm"
```

```tsx
<SlideToConfirm confirmedLabel="Payment sent" onConfirm={sendPayment}>
  Slide to pay $240.00
</SlideToConfirm>
```

## Composition

```text
SlideToConfirm           data-slot="slide-to-confirm" data-state [data-dragging]
├── span                 data-slot="slide-to-confirm-fill"
├── span                 data-slot="slide-to-confirm-label"
└── span                 data-slot="slide-to-confirm-thumb"
```

`data-state` is `idle` or `confirmed`. It stays confirmed; give it a new `key` to reset it.

## Motion

The thumb follows the pointer with no lag, and anywhere else (springing back, or on to the end) moves on the settle spring. Past either end it moves a quarter of the drag, up to a small stretch. Reduce Motion drops the springs; the thumb still follows the finger.

## API Reference

| Prop             | Type         | Default  |
| ---------------- | ------------ | -------- |
| `children`       | `ReactNode`  |          |
| `confirmedLabel` | `ReactNode`  | `"Done"` |
| `onConfirm`      | `() => void` |          |
| `disabled`       | `boolean`    | `false`  |

It renders a `button` and takes its props, except `onClick`.

## Accessibility

It is a button named by its label, with a description that says to slide or press Enter. Enter and Space confirm it at once, with the same slide, so the keyboard never has to drag. Once confirmed it is marked `aria-disabled` and shows the confirmed label.

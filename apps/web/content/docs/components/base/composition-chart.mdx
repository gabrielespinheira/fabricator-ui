Give it rows of data, the field that names each column (`index`) and a `config` that names the parts. Each row becomes a column stretched to the whole, split into its parts in the next colours of the [chart palette](#colours), so the chart reads as a mix rather than a size. Columns are wider than a Bar Chart's, at most 40px, with less air between them, and touching parts keep a 2px gap.

The legend lists every part with its share. With nothing inspected it reads the latest column; point at a column, drag a finger across the chart or tab to it and use the arrow keys, and the shares follow the inspected column while a tooltip gives each part's value and share. Pressing a part in the legend hides it, and the rest share the whole between them; pointing at it spotlights it.

Composition Chart is part of the Fabricator style. It's drawn in SVG, so the same component ships for every base, and its layout comes from the same model as the React Native version.

## Usage

```tsx
import { type ChartConfig } from "@/components/ui/chart-kit"
import { CompositionChart } from "@/components/ui/composition-chart"
```

```tsx
const data = [
  { date: "Nov 1", search: 3_800, direct: 2_630, social: 2_560 },
  { date: "Nov 2", search: 4_010, direct: 2_680, social: 2_480 },
  { date: "Nov 3", search: 4_100, direct: 2_620, social: 2_380 },
]

const config = {
  search: { label: "Search" },
  direct: { label: "Direct" },
  social: { label: "Social" },
} satisfies ChartConfig

<CompositionChart
  data={data}
  index="date"
  config={config}
  label="Share of visits by source"
/>
```

Give the parts as plain values; the chart works out each one's share of its column. A missing value leaves that part out of its column, and a negative one counts as nothing. The chart fills its container's width and is 18rem tall until you give it a height with `className`.

## Colours

Parts take the chart palette in the order of `config`, and keep their colour when another is hidden. Give a part its own with `color`: a palette slot, an upstream chart token (`chart-1` … `chart-5`), a role (`primary`, `info`, `success`, …), a CSS variable (`var(--brand)`) or any CSS colour.

| Token              | Hue    | Token              | Hue     |
| ------------------ | ------ | ------------------ | ------- |
| `--chart-series-1` | blue   | `--chart-series-5` | magenta |
| `--chart-series-2` | orange | `--chart-series-6` | green   |
| `--chart-series-3` | aqua   | `--chart-series-7` | violet  |
| `--chart-series-4` | amber  | `--chart-series-8` | red     |

The palette ships with the foundations, chosen separately for light and dark, every slot at 3:1 or more against the page and the card. Slots never repeat: a ninth part is grey, so fold small parts into an "Other" one before that.

## Motion

- **Grow:** the first time the chart scrolls into view, the columns grow from the baseline in a quick wave, on the `reveal` role, once per mount.
- **Morph:** when `data`, `config` or the visible parts change, each part moves and resizes to its new share on the `move` role. A part being shown grows in; one being hidden shrinks away while the others take its room.
- **Glide:** the column highlight and the tooltip glide between columns on the `glide` role.

All three follow the [motion speed](/docs/foundations/motion) of the region they sit in. Reduce Motion and the `instant` speed draw the chart at once and drop the glide; `animate={false}` does the same for one chart.

## API Reference

### CompositionChart

All other props go to the root `<div>`.

| Prop             | Type                                            | Default                       |
| ---------------- | ----------------------------------------------- | ----------------------------- |
| `data`           | `TDatum[]`                                      | required                      |
| `config`         | `ChartConfig`                                   | required                      |
| `index`          | `keyof TDatum`                                  | required                      |
| `label`          | `string`                                        | required: the accessible name |
| `formatValue`    | `(value: number, key: string) => string`        | `1,234`                       |
| `formatIndex`    | `(value: string, datum: TDatum) => string`      | the field as text             |
| `legend`         | `boolean`                                       | on for two or more parts      |
| `tooltip`        | `boolean`                                       | `true`                        |
| `animate`        | `boolean`                                       | `true`                        |
| `loading`        | `boolean`                                       | `false`                       |
| `empty`          | `ReactNode`                                     | "No data"                     |
| `onActiveChange` | `(active: ChartActive<TDatum> \| null) => void` | -                             |

### ChartConfig

| Field   | Type         | Default               |
| ------- | ------------ | --------------------- |
| `label` | `string`     | required              |
| `color` | `ChartColor` | the next palette slot |

### Data attributes

| Attribute                             | Element        | Present when                                   |
| ------------------------------------- | -------------- | ---------------------------------------------- |
| `data-slot="composition-chart"`       | root           | always                                         |
| `data-loading`                        | root           | `loading` is true                              |
| `data-slot="chart-plot"`              | the plot       | always                                         |
| `data-slot="chart-bar"`               | a part         | always; `data-dimmed` while another is spotlit |
| `data-slot="chart-band"`              | highlight      | a column is inspected                          |
| `data-slot="chart-legend"`            | the legend     | the legend shows                               |
| `data-slot="composition-chart-share"` | a part's share | the part is shown                              |
| `data-slot="chart-tooltip"`           | the tooltip    | a column is inspected                          |

## Accessibility

- The plot is a slider named after `label` ("Share of visits by source: inspect values"). Tab to it, then the arrow keys step through the columns, Home and End jump to the first and last, and Escape lets go. Its value text reads the tooltip: the column and every part's value and share.
- Every value is also in a table hidden from sight, so a screen reader can read the data without inspecting it.
- With two or more parts the legend always shows, so no part is told apart by colour alone. Its items are toggle buttons with `aria-pressed`, and each one's name includes its share.
- Text never takes a part's colour: names and shares stay in the text colours, beside a coloured key.
- `loading` sets `aria-busy` on the root and dims the last drawing until new data arrives.

## Usage

```tsx showLineNumbers
import { AspectRatio } from "@/components/ui/aspect-ratio"
```

```tsx showLineNumbers
<AspectRatio ratio={16 / 9} className="overflow-hidden rounded-xl bg-muted">
  <Image src="..." alt="..." fill className="object-cover" />
</AspectRatio>
```

The frame takes its width from its parent or `className`, and its height from `ratio`. Give it `overflow-hidden` and a radius to clip what's inside, and `bg-muted` so it holds its shape while an image loads.

## Changing the ratio

When `ratio` changes, the frame glides to the new shape on the move timing (`duration-move ease-move`, 250ms at the default [speed](/docs/foundations/motion)). Under reduced motion it snaps. The demo at the top switches between five ratios; its frame keeps the same area, so the photo reshapes around its centre.

## API Reference

### AspectRatio

The `AspectRatio` component displays content within a desired ratio.

| Prop        | Type     | Default | Required |
| ----------- | -------- | ------- | -------- |
| `ratio`     | `number` | -       | Yes      |
| `className` | `string` | -       | No       |

It also takes every `div` prop. A `style` prop merges with the ratio.

## Accessibility

- The frame is a plain `div` with no role, so screen readers read only what's inside it.
- Give every image inside it an `alt` that says what it shows, or `alt=""` when it's decoration. An `iframe` takes a `title`.
- A ratio switcher, as in the demo, is a `ToggleGroup` with an `aria-label`; each item's text names its ratio.

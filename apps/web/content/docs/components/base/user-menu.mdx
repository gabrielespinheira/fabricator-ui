User Menu shows who is signed in and opens their menu. The items are yours: pass Dropdown Menu groups as children.

- `variant="row"` fills a sidebar row with the avatar, the name and the email. Put it in the sidebar footer, or in the header.
- `variant="mark"` is the avatar alone, for a header or a sidebar header row.
- `UserMenuTheme` is the theme row: light, dark and system as small tabs.

User Menu is part of the Fabricator style.

## Usage

```tsx
import { UserMenu, UserMenuTheme } from "@/components/ui/user-menu"
```

```tsx
<SidebarFooter>
  <UserMenu
    user={{ name: user.name, email: user.email, avatarUrl: user.image }}
  >
    <DropdownMenuGroup>
      <DropdownMenuItem>Profile</DropdownMenuItem>
      <DropdownMenuItem>Settings</DropdownMenuItem>
    </DropdownMenuGroup>
    <UserMenuTheme theme={theme} onThemeChange={setTheme} />
    <DropdownMenuSeparator />
    <DropdownMenuGroup>
      <DropdownMenuItem onClick={signOut}>Sign out</DropdownMenuItem>
    </DropdownMenuGroup>
  </UserMenu>
</SidebarFooter>
```

Without an `avatarUrl`, the avatar shows the name's initials.

## Theme

`UserMenuTheme` goes among the menu's groups. Your theme provider owns the theme; with next-themes, pass `theme` and `setTheme` as they are:

```tsx
const { theme, setTheme } = useTheme()

<UserMenuTheme theme={theme} onThemeChange={setTheme} />
```

Picking a tab slides the pill to it and reveals the page from it, as [Theme Toggle](/docs/components/base/theme-toggle) does. The menu stays open, so people can try a theme and change their mind. The row keeps a snapshot of its own above the reveal, so its icons stay sharp while the page sweeps. A choice that doesn't change the page, such as from system to the theme the system already uses, only moves the pill.

The default reveal is the blurred circle. `variant` takes any of Theme Toggle's:

```tsx
<UserMenuTheme theme={theme} onThemeChange={setTheme} variant="blinds" />
```

## Placement

The menu opens to the right of a sidebar row, and below a mark or on phones. Set `side` and `align` to place it yourself.

## API Reference

### UserMenu

| Prop       | Type                                     | Default                                   |
| ---------- | ---------------------------------------- | ----------------------------------------- |
| `user`     | `{ name, email?, avatarUrl? }`           | -                                         |
| `variant`  | `"row" \| "mark"`                        | `"row"`                                   |
| `side`     | `"top" \| "right" \| "bottom" \| "left"` | right, or bottom for a mark and on phones |
| `align`    | `"start" \| "center" \| "end"`           | `"end"`                                   |
| `children` | Dropdown Menu groups                     | -                                         |

### UserMenuTheme

| Prop            | Type                                                                                                       | Default         |
| --------------- | ---------------------------------------------------------------------------------------------------------- | --------------- |
| `theme`         | `string \| undefined`: `"light"`, `"dark"` or `"system"`; any other value picks no tab                     | Required        |
| `onThemeChange` | `(theme: "light" \| "dark" \| "system") => void`                                                           | Required        |
| `variant`       | `"rectangle" \| "circle" \| "circle-blur" \| "blinds" \| "square" \| "diamond" \| "hexagon" \| "triangle"` | `"circle-blur"` |
| `start`         | `"trigger" \| "top-left" \| "top-right" \| "bottom-left" \| "bottom-right" \| "center" \| "bottom-up"`     | `"trigger"`     |
| `labels`        | `{ theme?: string; light?: string; dark?: string; system?: string }`                                       | English names   |

## Accessibility

- The trigger is a button; the mark is named "Account:" followed by the person's name.
- The menu starts with a label holding the avatar, the name and the email, then your items. Keyboard and focus behaviour come from Dropdown Menu.
- The theme row is a group of radio items named Light, Dark and System. The up and down arrows reach them like any item, left and right move between them, and Enter or Space picks one. Reduced motion changes the theme at once.

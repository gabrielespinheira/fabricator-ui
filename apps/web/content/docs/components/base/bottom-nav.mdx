A bottom nav is the tab bar of an app on a phone. The current tab opens into a pill with its name while the others close to their icons, so the bar stays short and the current place is always named. Picking a tab pops its icon.

Bottom Nav is part of the Fabricator style. It's built on HTML, so the same component ships for every base.

## Usage

```tsx
import {
  BottomNav,
  BottomNavItem,
  BottomNavLink,
} from "@/components/ui/bottom-nav"
```

```tsx
<BottomNav aria-label="Main">
  <BottomNavLink href="/" label="Home" icon={<HomeIcon />} active />
  <BottomNavLink href="/search" label="Search" icon={<SearchIcon />} />
</BottomNav>
```

## Composition

```text
BottomNav                data-slot="bottom-nav" (nav)
└── BottomNavItem        data-slot="bottom-nav-item" [data-active] [aria-current="page"]
    ├── span             data-slot="bottom-nav-icon"
    └── span             data-slot="bottom-nav-label-frame"
```

`BottomNavLink` renders a link for tabs that go to a page; `BottomNavItem` a button for tabs that switch a view in place. Mark the current one with `active`. Place the bar yourself, such as fixed to the bottom of the screen.

## Motion

The current tab's name opens to its width on the soft spring as the old one closes, so the pills trade room. Pressing squashes the icon and letting go pops it back on the pop spring. Reduce Motion opens and closes at once.

## API Reference

| Component                        | Prop     | Type        |
| -------------------------------- | -------- | ----------- |
| `BottomNavItem`, `BottomNavLink` | `label`  | `string`    |
|                                  | `icon`   | `ReactNode` |
|                                  | `active` | `boolean`   |

`BottomNav` renders a `nav`, `BottomNavLink` an `a` and `BottomNavItem` a `button`, each taking its element's props.

## Accessibility

The bar is a `nav`; name it with `aria-label`. Every tab keeps its name in the page, so screen readers read it even when the pill is closed, and the current one is marked `aria-current="page"`. Tabs are reached with Tab and activated with Enter.

Put it under a new-password field: four bars fill one after another as the password gets stronger, from the destructive role through warning to success, and a word says how strong it is. The score comes from length and the kinds of character used; anything shorter than eight characters stays weak.

Password Strength is part of the Fabricator style. It's built on HTML, so the same component ships for every base.

## Usage

```tsx
import {
  PasswordStrength,
  PasswordToggle,
} from "@/components/ui/password-strength"
```

```tsx
<Field>
  <FieldLabel htmlFor="new-password">New password</FieldLabel>
  <InputGroup>
    <InputGroupInput
      id="new-password"
      type={visible ? "text" : "password"}
      value={password}
      onChange={…}
    />
    <InputGroupAddon align="inline-end">
      <PasswordToggle visible={visible} onVisibleChange={setVisible} />
    </InputGroupAddon>
  </InputGroup>
  <PasswordStrength value={password} />
</Field>
```

## Composition

```text
PasswordStrength         data-slot="password-strength" data-score
├── div                  (the bars)
│   └── span             data-slot="password-strength-bar" [data-filled]
└── span                 data-slot="password-strength-label"

PasswordToggle           data-slot="password-toggle" [data-visible] aria-pressed
```

`data-score` is 0 (nothing typed) to 4. `labels` renames the five words, from nothing typed to strong. It shows strength; keep the server's own rules for what it accepts. `PasswordToggle` shows and hides the password; put it in the field's end addon and switch the input's `type` with it.

## Motion

Each bar fills from its start on the soft spring, a stagger after the bar before it when several fill at once; emptying runs at once. The colour changes on the same spring, and a new word rises in. Reduce Motion fills and empties at once. The toggle's eye draws a slash across itself while the password is hidden and retracts it as the text shows, and its pupil shrinks to half and pops back on the pop spring.

## API Reference

| Prop     | Type                                       | Default                                  |
| -------- | ------------------------------------------ | ---------------------------------------- |
| `value`  | `string`                                   |                                          |
| `labels` | `[string, string, string, string, string]` | `["", "Weak", "Fair", "Good", "Strong"]` |

The root is a `div` and takes its props.

| `PasswordToggle` prop | Type                         |
| --------------------- | ---------------------------- |
| `visible`             | `boolean`                    |
| `onVisibleChange`     | `(visible: boolean) => void` |

`PasswordToggle` renders a `button` and takes its props, except `onClick`.

## Accessibility

The bars are hidden from screen readers; the word is read instead, prefixed "Password strength", and announced politely as it changes. Colour never carries the score alone: the word says it. The toggle is a button named "Show password" or "Hide password", with `aria-pressed` for whether the text shows.

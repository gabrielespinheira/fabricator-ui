Give it a Markdown string and it draws headings, lists and tasks, quotes, code, tables, images and links in the document type role the [Editor](/docs/components/radix/editor) uses, so a preview looks like what was written. It has its own parser with no dependencies, and anything the parser doesn't model (HTML, footnotes, math) shows as its source instead of disappearing.

Markdown is part of the Fabricator style. It renders plain HTML with no hooks, so the same component ships for every base and works in Server Components, and the same parser runs in the [React Native version](/docs/components/native/markdown).

## Composition

```text
Markdown    parses the string and draws its blocks
```

One part. To change how links or images render, pass `components`; for the parsed document itself, `parseMarkdown` in `lib/markdown-parse.ts` returns the blocks and their runs.

## Supported syntax

| Syntax                                                             | Drawn as                                |
| ------------------------------------------------------------------ | --------------------------------------- |
| `#` to `######` headings, and underlined (setext) ones             | Headings 1 to 6                         |
| Paragraphs, hard line breaks                                       | Paragraphs                              |
| `-`, `*`, `+` and numbered lists, nested by indentation            | Lists, numbered from their first item   |
| `- [ ]` and `- [x]` task items                                     | A read-only checkbox; done items struck |
| `>` quotes                                                         | A muted block behind a bar              |
| Fenced and indented code                                           | A code panel like Syntax Highlight's    |
| `---`, `***`, `___`                                                | A divider                               |
| GitHub tables                                                      | A table, aligned per column             |
| An image alone on its line                                         | An image                                |
| `*em*`, `**strong**`, `~~strike~~`, `` `code` ``, links, autolinks | Inline formatting                       |
| Frontmatter                                                        | Not drawn                               |
| Anything else                                                      | Its source, monospace and muted         |

## API Reference

### Markdown

All other props go to the root `<div>`.

| Prop         | Type                                         | Default     |
| ------------ | -------------------------------------------- | ----------- |
| `children`   | `string`                                     | required    |
| `size`       | `"sm" \| "default" \| "lg"`                  | `"default"` |
| `components` | `{ a?: ComponentType, img?: ComponentType }` | -           |
| `syntax`     | `MarkdownSyntax[]`                           | -           |

## Accessibility

- It renders semantic HTML: headings, lists, `blockquote`, `pre`, `table` with a header row, so screen readers navigate it as a document.
- Task checkboxes are disabled inputs labelled "Done" or "Not done".
- Images take their alt text from the Markdown; write it there.
- Links keep their own text; a link with no text reads its address.

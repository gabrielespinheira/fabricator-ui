A delta says how a number moved since the period it is compared with: a sign, one decimal and an arrow. It is green when the number moved the way it should and red when it didn't, so a fall in churn is good news. Rates change in points ("−0.4 pt"). No change is an outline "0%", and a missing comparison says "No data" instead of pretending to be zero.

Delta is part of the Fabricator style. It's built on Badge, so the same component ships for every base.

## Usage

```tsx
import { Delta } from "@/components/ui/delta"
```

```tsx
<Delta change={12.4} />
<Delta change={-0.4} isGoodWhenUp={false} unit="pt" />
```

In a stat card, the delta sits in the header's action, beside the title:

```tsx
<CardHeader>
  <CardTitle>Money in</CardTitle>
  <CardAction>
    <Delta change={11.5} />
  </CardAction>
</CardHeader>
```

## API Reference

| Prop           | Type             | Default     |
| -------------- | ---------------- | ----------- |
| `change`       | `number \| null` |             |
| `isGoodWhenUp` | `boolean`        | `true`      |
| `unit`         | `"%" \| "pt"`    | `"%"`       |
| `locale`       | `string`         | the browser |
| `emptyLabel`   | `string`         | `"No data"` |

`change` is in the unit's terms (12.4 for 12.4%). It rounds to one decimal, so a change under 0.05 reads as no change. The rest of the props go to the `Badge`.

## Accessibility

The sign and the arrow carry the direction, so colour is never the only cue, and the label reads as text ("+12.4%"). Name what the delta compares with once, near the numbers, such as "Compared with the previous 30 days" in the page's toolbar.

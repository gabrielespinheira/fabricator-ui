## Composition

Use the following composition to build `Tabs`:

```text
Tabs
├── TabsList
│   ├── TabsTrigger
│   └── TabsTrigger
├── TabsContent
└── TabsContent
```

## Subtle

Use `variant="subtle"` on `TabsList` for a compact row without a track. Only the active tab shows its label; the others show their icon, so give every trigger an icon and a text label.

## API Reference

See the [Radix Tabs](https://www.radix-ui.com/docs/primitives/components/tabs#api-reference) documentation.

### TabsList

| Prop      | Type                    | Default     |
| --------- | ----------------------- | ----------- |
| `variant` | `"default" \| "subtle"` | `"default"` |

`variant="line"` is still accepted, so existing code keeps compiling, and renders as `"default"`.

## Accessibility

- Keyboard behaviour and roles come from the primitive: arrow keys move between tabs, and `orientation="vertical"` switches them to up and down.
- In a subtle list, the labels of inactive tabs are hidden visually but stay in each tab's accessible name.
- The active tab never changes weight or size, so the row never shifts when the selection moves.

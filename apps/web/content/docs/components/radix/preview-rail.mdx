Move the pointer along the rail: the ticks swell around the one it's on, like a dock, and a card beside the rail names that section. The card glides from tick to tick. With the pointer away, the swell rests on the current section, so the rail still shows where the reader is. On a touch screen a finger scrubs: a press lights the tick under it, a drag moves the light, and lifting on the rail follows the lit section.

Preview Rail is part of the Fabricator style. It's built on HTML, so the same component ships for every base.

## Usage

```tsx
import { PreviewRail } from "@/components/ui/preview-rail"
```

```tsx
<PreviewRail
  aria-label="On this page"
  defaultValue="installation"
  items={[
    { value: "overview", label: "Overview", href: "#overview" },
    {
      value: "installation",
      label: "Installation",
      description: "Add the CLI and set up your first project.",
      href: "#installation",
    },
    { value: "usage", label: "Usage", href: "#usage" },
  ]}
/>
```

Use it for a page's sections or a sequence of places, such as chapters, months or steps, where the rail is compact and the names can wait for the pointer. When people need to read every name at once, use `Tabs` or a `Sidebar` instead. An item with an `href` is a link; without one it's a button, and `onValueChange` says which was chosen.

## Composition

Preview Rail is one component. Its parts carry a `data-slot` for styling from outside:

```text
PreviewRail                      data-slot="preview-rail"
├── div (the rail)               data-slot="preview-rail-list"
│   └── a | button (one a tick)  data-slot="preview-rail-item" data-current data-lit
│       └── span                 data-slot="preview-rail-tick"
└── div (the card's track)       data-slot="preview-rail-preview"
    └── div                      data-slot="preview-rail-card" data-open | data-closed
        └── div                  data-slot="preview-rail-content"
            ├── p                data-slot="preview-rail-title"
            └── p                data-slot="preview-rail-description"
```

## Motion

The ticks swell on the move timing: the lit one to its full length, the next ones to three quarters and three fifths, and the rest stay short. The card grows from the rail on the popup motion, glides between ticks on the move timing, and its content fades in as it arrives. Near the ends of the rail it stops at the rail's edge rather than running past it. It closes quicker than it opens.

Everything follows the speed setting. Reduce Motion keeps the fades and drops the swell's travel, the glide and the growth.

## API Reference

### PreviewRail

| Prop            | Type                                   | Default                                          |
| --------------- | -------------------------------------- | ------------------------------------------------ |
| `items`         | `PreviewRailItem[]`                    | Required                                         |
| `orientation`   | `"vertical" \| "horizontal"`           | `"vertical"`                                     |
| `side`          | `"start" \| "end"`                     | `"end"` when vertical, `"start"` when horizontal |
| `value`         | `string`                               | (none)                                           |
| `defaultValue`  | `string`                               | The first enabled item                           |
| `onValueChange` | `(value: string) => void`              | (none)                                           |
| `renderPreview` | `(item: PreviewRailItem) => ReactNode` | The item's label and description                 |
| `aria-label`    | `string`                               | `"Section navigation"`                           |

The root is a `nav` and takes its props and `ref`. `side` places the card: `end` after a vertical rail (on its right) or below a horizontal one, `start` before a vertical rail or above a horizontal one.

### PreviewRailItem

| Field         | Type                        | Notes                                       |
| ------------- | --------------------------- | ------------------------------------------- |
| `value`       | `string`                    | Unique among the items                      |
| `label`       | `string`                    | The tick's name, and the card's title       |
| `description` | `ReactNode`                 | Under the title, and the tick's description |
| `href`        | `string`                    | Makes the tick a link                       |
| `target`      | `HTMLAttributeAnchorTarget` | `_blank` adds `rel="noreferrer noopener"`   |
| `rel`         | `string`                    |                                             |
| `disabled`    | `boolean`                   | Dims the tick and skips it                  |

## Accessibility

Preview Rail is a navigation landmark, named by `aria-label`. Every tick is a link or a button named by its item's label, with the description as its description, and the current one carries `aria-current` (`page` on a link). The card repeats what the tick already says, so screen readers skip it.

| Key    | Does                                      |
| ------ | ----------------------------------------- |
| Tab    | Moves to the next tick and shows its card |
| Enter  | Follows the link, or chooses the item     |
| Space  | Chooses the item (buttons)                |
| Escape | Hides the card                            |

On a touch screen, a press on the rail lights the tick under the finger and shows its card, a drag along the rail scrubs instead of scrolling the page, and lifting on the rail follows the lit tick. Lifting away from the rail chooses nothing.

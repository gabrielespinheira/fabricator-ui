Fabricator UI is a registry of components, blocks and themes. The CLI copies each component's source into your project, where you read it, change it and ship it like the rest of your code.

## Open code

Every component arrives as a plain TypeScript file styled with Tailwind. To change a button, you edit the button: there is no wrapper to override and no compiled package to work around.

## Three bases, one look

Each web component is written against a primitive library, called a base. Pick one when you create a project and the CLI installs the matching source.

| Base       | Built on                | Id      |
| ---------- | ----------------------- | ------- |
| Base UI    | `@base-ui/react`        | `base`  |
| Radix UI   | `radix-ui`              | `radix` |
| React Aria | `react-aria-components` | `aria`  |

Base UI is the default. A component looks and behaves the same in every base, so the choice is about the primitives you already know.

## Web, mobile and desktop

Every component has a [React Native](/docs/installation/react-native) version under the same name, with the same variants and tokens. On the desktop, Electron and Tauri load the same React app as the web, and the [App Shell](/docs/components/base/app-shell) lays out the window like a native app, with the sidebar beside the traffic lights. See [install methods](/docs/installation/install-methods) for each platform.

## Works with shadcn/ui

Fabricator UI keeps the shadcn/ui API, so it drops into an existing project:

- A component that replaces a shadcn/ui component keeps its name, file path, exports, props, variants and `data-slot` attributes, and only adds to them.
- Components read the same CSS variables (`--background`, `--primary`, `--radius`, …), so your theme carries over.
- `npx fabricator-ui@latest init` adds the `@fabricator` [registry](/docs/registry) next to the components you already have.

## One style

Components ship in the Fabricator style, the look you see in these docs. They are written with semantic classes and compiled into that style at build time, so the code you install is plain Tailwind. Colours, radius and fonts come from your theme's CSS variables.

## Ready for AI tools

Plain source and consistent APIs are easy for AI tools to read and extend. Every docs page has a Markdown version (add `.md` to its URL), the site publishes an [llms.txt](/llms.txt), the [MCP server](/docs/mcp) browses and installs from `@fabricator`, and the [agent skill](/docs/skills) teaches your agent to design with the library.

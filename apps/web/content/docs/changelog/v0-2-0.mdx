Version 0.2.0 of the `fabricator-ui` CLI and the registry brings the full Fabricator design language.

- **Design system:** surfaces, interaction tokens, motion tiers, scrollbars and a new look for every component. See [Foundations](/docs/foundations/colors).
- **Fluid Hover:** one gliding highlight across menus, select, combobox, command, tabs, sidebar, accordion and table, in all three bases.
- **Sounds, pill radius and surface tint:** `@fabricator/sounds`, `@fabricator/radius-pill`, and a base colour that tints every surface.
- **Search and Sidebar:** a new Search component, and a Sidebar that resizes, peeks and collapses its sections.
- **Checkbox and radio:** redesigned, with a fixed selected-day hover in Calendar.
- **Removed:** Native Select and Chart are left out of Fabricator mode, and RTL support is dropped. Blend mode still ships every upstream item.

Update an existing project with:

```bash
npx fabricator-ui@latest add foundations
```

## Introducing Fabricator UI

**Fabricator UI is a component registry for building your own design system.**

This first release starts from [shadcn/ui](https://github.com/shadcn-ui/ui) (MIT) at commit [`295a1f11`](https://github.com/shadcn-ui/ui/commit/295a1f11).

### What's included

- **A complete component set**, with examples, blocks and charts.
- **Three bases:** each component is available for Base UI, Radix UI and React Aria, with the same API and `data-slot` attributes in all three.
- **Eight styles:** `vega`, `nova`, `maia`, `lyra`, `mira`, `luma`, `sera` and `rhea`, compiled from the same source.

### The @fabricator registry

Everything is served from the `@fabricator` registry at `https://fabricator-ui.vercel.app/r`. Install any item with the CLI:

```bash
npx fabricator-ui@latest add button
```

The registry has two modes:

- **Blend mode** (`/r/{style}/{name}.json`) compiles components in your current style, for existing projects.
- **Fabricator mode** (`/r/fabricator/{style}/{name}.json`) compiles components in the Fabricator design for your base. The Fabricator design is still in progress.

See [Registry](/docs/registry) for how to configure them.

### The fabricator-ui CLI

`fabricator-ui` sets up the `@fabricator` registry, maps bare names to it, and adds a `doctor` command to check your project.

```bash
npx fabricator-ui@latest init
```

In an existing project, `init` can add the registry without touching your theme. See [CLI](/docs/cli) for every command.

### What's next

The components use the default styles for now. Next we are building the Fabricator design language: new tokens for surfaces and motion, the Fabricator styles, and new components. Every change stays a superset of the existing component APIs, so code written for shadcn/ui keeps working.

## The Fabricator style

**The Fabricator style is here.** Fabricator mode (`/r/fabricator/{style}/{name}.json`) now compiles every component in the Fabricator design, for Base UI, Radix UI and React Aria.

### Foundations

Every Fabricator component installs the new `@fabricator/foundations` item. It adds tokens under new names; the existing theme tokens keep their names and meaning.

- **Surfaces:** eight elevation levels (`bg-surface-1` to `bg-surface-8`), each paired with a shadow (`shadow-surface-1` to `shadow-surface-8`). Containers are separated by shadow, not borders.
- **Interaction:** `bg-hover`, `bg-active` and `bg-selected` overlays, and a single blue focus ring.
- **Motion:** spring easings (`ease-spring`, `ease-spring-bounce`) and a quicker `ease-exit`, in three speed tiers. Under reduced motion, components keep their fades and drop slides and zooms.
- **Scrollbars:** thin, low-contrast scrollbars on fine pointers, plus a `scrollbar-hide` utility. Touch devices keep their native scrollbars.
- **Type:** `weight-*` utilities that pair the Inter weight with its optical size.

### Fluid Hover

`@fabricator/fluid-hover` adds one highlight that glides to the item nearest the pointer, so moving across a list never flickers between items. Selection backgrounds slide between selected items, and keyboard navigation moves the same highlight.

Menus, select, combobox, command, navigation menu, menubar, tabs, toggle group, sidebar, accordion and table use it, for Base UI, Radix UI and React Aria (React Aria has no menubar or navigation menu). Their APIs are unchanged: Fluid Hover is wired inside the components.

### Restyled components

Every component is restyled for the Fabricator style: 36px controls, 13px text, rounded items inside rounded containers, and raised popups on `surface-3`. With the default preset (or any Fabricator preset), `init` also installs the Fabricator colour palette; other presets keep their own colours.

### The website

The docs now read like the components feel: a sidebar with search and a new **Foundations** section (Fluid Hover, Motion, Scrollbars, Sizes, Surfaces, Typography), a side panel for theme and primitive, and a homepage gallery of live components.

### Fixes

- React Aria: removed an unused type import from `alert-dialog` that failed the Vite template's type check.
- Fabricator mode: vertical tabs now pass their orientation to the primitive, so the up and down arrow keys move between tabs and the list announces the right orientation.

## Sounds, Search and more

### Sounds

`@fabricator/sounds` adds interface sounds, synthesized with the Web Audio API: no audio files and no dependencies. There are 32 short sounds, one for each kind of component: buttons by weight (primary, secondary, destructive), rows and links, checkboxes, switches, toggles, radios and options, tabs, pagination, carousels, accordions, menus, dialogs, alert dialogs, sheets and drawers, toasts by type, sliders, resizable handles and refusals. The catalogue is inspired by [Bencho's sound library](https://bencho.dev/sounds); the sounds themselves are our own, except the switch pair, which comes from Bencho's liquid toggle.

Mount `<SoundEffects />` once at the root of your app and every component plays the right sound, in every base, with no changes to the components themselves. Sounds are off until you turn them on. Sounds and the pill radius also install in existing projects that keep their own style, because they only rely on attributes every component shares. Use `data-sound` to change or silence a sound, and `playSound` or `useSound` for your own interactions. See [Sounds](/docs/foundations/sounds).

```bash
npx fabricator-ui@latest add sounds
```

### Search

Search is a new component: a round search button that springs open into the field as one object, takes focus, and closes again on Escape or when you leave it empty. It has `default` and `outline` variants, three sizes, a clear button, and controlled or uncontrolled `open` and `value`. See [Search](/docs/components/base/search).

```bash
npx fabricator-ui@latest add search
```

### Status colours

Info, success, warning and error each have a full palette: a solid for icons and fills, a text colour, a hairline border, and an eight-level tinted surface ladder that pairs with the surface shadows. Every pair meets WCAG AA in light and dark. See [Colors](/docs/foundations/colors).

- **Alert:** `info`, `success`, `warning` and `error` variants, and a `contrast` prop. `low` (the default) keeps the neutral panel and colours the icon; `high` tints the whole alert with a status hairline. See [Alert](/docs/components/base/alert#status).
- **Badge:** `info`, `success`, `warning` and `error` variants. See [Badge](/docs/components/base/badge#status).
- **Toast and Sonner:** success, info, warning and error icons take their status colour.

The new variants are additive: `default` and `destructive` are unchanged.

### Checkbox and Radio Group

Both are 18px with a quiet outline. Checked, they fill with the foreground colour, and an inverted check or dot pops in on the bouncy spring. They give a little when pressed, and focus is the 1px ring with an offset. The check wipes in on the bouncy spring and fades out when cleared; switching radios crossfades the dots.

### Collapsible

Collapsible now looks and moves like Accordion: a title row with a chevron that turns on the spring, and content that opens and closes with the same height animation.

### Questionnaire

Questionnaire now uses the library's own controls. Single-choice answers show the Radio Group mark and multiple-choice answers the Checkbox mark, both lit by the whole row, so hovering or pressing a row firms or presses its mark. The free-text answer is the Input, lined up with the question text, and shortcut keys are Kbd keycaps. Rows read like Field choice cards: foreground labels, a hover tint, and the active fill once chosen.

### Cursors

Every Fabricator component now shows the cursor that matches what a press does:

- `pointer` on anything that activates: buttons, toggles, tabs, accordion triggers, checkboxes, radios, switches, select and combobox triggers, and every menu, select, combobox and command row. Labels of checkboxes, switches and radios get it too.
- `text` on input-OTP slots and the combobox chips row.
- `grab`, then `grabbing`, on slider thumbs and drawer handles; the slider track is `pointer`.
- `not-allowed` on disabled controls and slider thumbs, and on buttons that stay focusable while disabled.

The rules live in the style, so `className` still overrides them.

### Pill radius

Every corner comes from the `--radius` token. `@fabricator/radius-pill` sets it to `1.25rem`, so controls become full pills and containers stay concentric with their items. See [Density](/docs/foundations/density#rounded-or-pill).

```bash
npx fabricator-ui@latest add radius-pill
```

### Surface base colour

Every surface is now calculated from one base colour, held by `--surface-hue` and `--surface-chroma`. Both default to `0`, the neutral ladder, so nothing changes until you set them. Set them and every level takes the tint, in light and dark mode, and text keeps its AA contrast. The [Colors](/docs/foundations/colors#base-colour) page has hue and strength sliders that preview both themes and generate the CSS.

```bash
npx fabricator-ui@latest add foundations
```

### Motion speeds

The three motion tiers are now tokens: fast 90ms, moderate 210ms and slow 290ms, with exits at 70ms, 160ms and 220ms. Components use the `duration-fast`, `duration-moderate` and `duration-slow` utilities (and their `-exit` forms), and `--motion-scale` scales every one of them at once. See [Motion](/docs/foundations/motion).

### Smoother rendering

- The foundations turn on grayscale font anti-aliasing, legibility and kerning, optical sizes, and no faux bold or italic, for every app that uses Fabricator components.
- Dialogs and alert dialogs are centered without a half-pixel `translate`, so their text stays sharp at every window size.

### Site settings

The header, the docs sidebar and the docs side panel have a settings menu:

- **Theme:** light or dark.
- **Sound:** turns the component sounds on or off.
- **Icons:** Lucide (the default), Tabler, HugeIcons, Phosphor or Remix Icon, applied live to every preview.
- **Radius:** Rounded or Pill.
- **Motion:** Relaxed, Default, Snappy or Off, scaling every animation.
- **Surface:** Neutral, a tinted preset (Slate, Sand, Sage, Ocean, Indigo, Plum, Rose), or a custom tint from the Surfaces page, applied to the whole site.

### Removed

- **Right-to-left docs and demos.** Fabricator UI is left-to-right only; the RTL guide, sections and demos are gone.
- **Native Select** is no longer part of the Fabricator library: it only restyled the browser's own `<select>`. Use [Select](/docs/components/base/select). Blocks and examples that used it now use Select. Projects that keep their own style can still install it.

### Fixes

- Every kind of component has its own sound, and each family its own material: buttons knock, selection controls click, rows tick, tabs ring, menus pop, dialogs bloom, sheets slide and toasts chime by type. Primary and destructive buttons now sound different from the others in Base UI too.
- Scroll Area fades its edges where there is more to scroll.
- Sonner toasts (Radix, React Aria) now get the Fabricator style.
- Calendar and Date Picker: hovering the selected day no longer hides its number, and keyboard focus uses the 1px focus ring.
- Sidebar rows that open a collapsible now get the Fluid Hover highlight in every base.

## Sidebar

Sidebar keeps every part and prop it had, and adds:

- **Resize:** drag `SidebarRail` to resize the sidebar between 160px and 360px. Drag past the minimum to collapse it; click the rail to collapse or expand. Its tooltip explains both and shows the shortcut.
- **Peek:** `peek="hover"` (or `"click"`) on `SidebarProvider` floats a collapsed sidebar out as a card from its edge or its trigger, without pinning it open.
- **Collapsible sections:** `collapsible` on `SidebarGroup` turns its label into an accordion toggle with a hover-revealed chevron. `SidebarGroupActions` holds up to three actions on the label row.
- **Rows:** `icon`, `status` (`active`, `unread`, `idle`) and `dot` on `SidebarMenuButton`; `SidebarMenuActions` for several row actions; labels stop exactly short of badges and actions; `open` on `SidebarMenuSub` collapses a sub-tree on the moderate spring.
- **Keyboard:** Arrow keys, Home and End move between rows. `shortcut` on the provider changes or turns off the <Kbd>⌘B</Kbd> toggle; a bare key like `"["` works too.
- **Toggle:** the trigger's panel glyph morphs between open and closed, mirrors for a right-side sidebar, and its tooltip names the action and the shortcut.

The docs page now shows every example live at desktop width. See [Sidebar](/docs/components/base/sidebar).

```bash
npx fabricator-ui@latest add sidebar
```

### Removed

- **Chart** is no longer part of the Fabricator library for now, and neither are its docs pages, the Charts gallery or the Dashboard block built on it. Projects that keep their own style can still install them.
- **The Create and Colors pages** are gone from the site for now. Preset codes still work with `init --preset` and `apply`.

The registry now serves the Fabricator style only, sounds play as soon as they are mounted, and Tabs keep their track on raised surfaces.

## One registry style

The registry now serves one style: the Fabricator design shown in these docs. Blend mode, which compiled components in your project's own shadcn style, is removed.

- **One registry URL:** `https://fabricator-ui.vercel.app/r/fabricator/{style}/{name}.json`. The base is read from your `style` field, and colours, radius and fonts come from your theme.
- **Old URLs keep working:** `https://fabricator-ui.vercel.app/r/{style}/{name}.json` redirects to the Fabricator style. Run `npx fabricator-ui@latest doctor` to find it, then update the `@fabricator` entry in `components.json`.
- **CLI:** `init` and `apply` no longer accept `--blend`. "Add the @fabricator registry only" writes the new URL.

See [Registry](/docs/registry).

## Sounds on by default

`@fabricator/sounds` now starts with sounds on. Mount `<SoundEffects />` and every component plays its sound right away, with no extra setup. To let people turn sounds off, pass their preference as `<SoundEffects enabled={soundsOn} />` or call `setSoundsEnabled(false)`. The docs site plays sounds by default too, and the Sound setting turns them off.

See [Sounds](/docs/foundations/sounds).

## Tabs track on any surface

The default Tabs track used `bg-muted`. In dark mode `muted` is the same colour as `surface-2`, so Tabs placed on a `surface-2` card lost their track. The track is now `bg-foreground/[0.05]`, a translucent step over whatever sits underneath, in every base. Run `npx fabricator-ui@latest add tabs` to update, or `npx fabricator-ui@latest diff tabs` to see the change first.

See [Tabs](/docs/components/base/tabs).

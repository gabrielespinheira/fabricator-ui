title: November 2026 - Simpler documentation navigation
description: Documentation without tabs or a right panel, and direct component browsing across platforms.
date: 2026-11-10
---

The website docs use one routed page in the App Shell, without tabs or a right panel. Those options are also removed from the docs homepage settings.

The Library page is removed from the docs, desktop example and mobile example. Browse components directly through Basics, Forms, Overlays, Structure, Content and Chat. Existing Library links return to the overview; component links still open their demos. Desktop and mobile keep their component tabs and Details panel.

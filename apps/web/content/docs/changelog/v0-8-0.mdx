Seven new components, from a full Data Table to a Theme Toggle that reveals the new theme across the page. Accordion, Checkbox, Radio Group and Slider gain motion, and Date Picker now picks months and years, replacing Month Input.

## New components

### Data Table

Data Table used to be a guide. Now `npx fabricator-ui@latest add data-table` installs a TanStack Table v9 setup (`useDataTable`), typed cells and the parts that draw it, on every base.

Each column's `meta.type` (text, number, currency, percent, progress, date, status, tags, person, link, email or boolean) picks its cell, its filter, its editor, its sort, its alignment and its footer calculations. A header sorts on click, with Shift for a second sort, and its options popover filters the way Notion does: a condition and the value it calls for, from "contains" and "is between" to "is within the past week", "has all of" and "is empty". Columns pin to either edge, resize from their edge or the keyboard, and hide from their popover.

`useDataTable({ load })` feeds the table a window of rows at a time: the scroll covers every match and loads the windows in view, even after a jump or a fling, with skeleton rows meanwhile, pages with `paginate`, a fresh first window on a new sort, filter or search, aborted stale requests, and footer figures from the server. `queryRows` and `summarizeRows` answer a query the way the table would, so a TypeScript server can use them as is. Rows in memory still go in `data`.

Cells edit in place with `meta.editable` and `onCellChange`: inputs for text and numbers, pickers for statuses, people and tags, a Calendar for dates and a Checkbox for booleans.

The settings at the end of the header set the density and switch the calculations, row numbers, stripes and column lines, show and hide columns, and clear the sort and filters, so everything but the search happens inside the table. `defaultView`, or `view` with `onViewChange`, sets them from code.

Rows are virtual, so 10,000 of them scroll like a screenful, without bouncing at either edge. Rows, cells, the header and the footer redraw only when what they show changes, a column resize restyles no cells, and the checkboxes and avatars in rows are light enough that picking every row or scrolling fast stays smooth. Skeleton, refresh and error states, an Empty for no results, Shift-click ranges, a floating selection bar and a footer of calculations come with it.

React Native keeps the Table-based example for now; a native Data Table is planned.

### Multi Select

Multi Select is a new form control for picking several options from a searchable list. It's built on each base's Combobox in multiple mode, so filtering, the keyboard and ARIA come from Base UI or React Aria, and it shares Combobox's frame, popup and rows.

Each pick becomes a chip that rises in from a small scale. A removed chip fades and wipes out where it stands while the chips after it glide over at the same time. The list stays open between picks and the search clears after each one; Backspace in an empty search removes the last chip. One shared highlight glides between options as the pointer moves, and holding an option fills it and presses it in. Every motion follows the motion speed and stops under reduced motion.

React Native opens the list in a dialog like Combobox, with the same chips and motion. Install it with `npx fabricator-ui@latest add multi-select`.

### Rating

`npx fabricator-ui@latest add rating` adds a row of stars that holds a score. Hover previews it, a click or a drag sets it, and `step={0.5}` takes half stars.

- **Colours and sizes.** The default stars are yellow; `variant` fills them with your primary colour or a status colour, and `size` takes `sm`, `default` and `lg`.
- **Read-only.** `readOnly` shows an average with its exact fraction, such as 4.3, and reads it to screen readers as "4.3 out of 5 stars".
- **A slider for everyone.** It's one focusable slider from 0 to `max`: the arrows, Page Up, Page Down, Home, End and the digits set it. `name` submits it with a form, and `aria-invalid` turns the empty stars red.
- **React Native.** The same API: a tap sets the score, a horizontal drag scrubs it with a notch each step, and a star the score reaches pops in on the bounce spring.

### Audio Player

`npx fabricator-ui@latest add audio-player` adds an audio file on a card: the artwork, the title and the artist, the seek bar, the time played and left, the speed, back and forward 10 seconds, play and the volume.

- **Waveform.** Pass `peaks` and the seek bar draws the file's waveform. The bars rise in when they first draw, fill in primary as the playhead crosses them and darken under the pointer. `getAudioPeaks` works the peaks out from decoded samples, once, when the file is made or uploaded.
- **Cover and compact.** `variant="cover"` puts a large artwork above the controls that grows to full size while the music plays. `variant="compact"` keeps play, the waveform, the time and the speed on one pill-shaped row, as a voice message.
- **Motion.** Play and pause trade places by scaling and blurring through each other, three bars bounce beside the title while it plays, and the skip arrows wind as you press them. Everything follows the motion speed and stops with reduced motion.
- **Keyboard.** The Video Player's keys: Space or K, J and L, the arrows, M, the digits and < and >. The seek bar and volume are sliders.

### Image Compare

`npx fabricator-ui@latest add image-compare` adds two pictures of one scene in a single frame, split by a line you drag. Labels in the top corners name both sides and fade as the line reaches them.

- **Jelly line.** The line's ends trail the knob on a soft spring, and the "before" picture is cut along the same curve, so the picture bends with the line. A click glides the knob there and a flick sends it to the edge.
- **A slider for everyone.** It's one focusable slider from 0 to 100: the arrows, Page Up, Page Down, Home and End move it, and screen readers hear both shares, such as "Before 30%, After 70%". `value` and `onValueChange` drive it from outside.
- **React Native.** The same API with the same physics on the UI thread: a horizontal drag moves the line, a vertical one scrolls, and each step notches with a sound and a haptic.

### Preview Rail

`npx fabricator-ui@latest add preview-rail` adds a compact navigation rail: one thin tick per section. The ticks swell around the pointer like a dock, and a card beside the rail names the section and describes it. With the pointer away, the swell rests on the current section.

- **One card that travels.** The card grows from the rail on the popup motion, glides from tick to tick on the move timing, and its content fades in as it arrives. Reduce Motion keeps the fades only.
- **Vertical or horizontal.** `orientation` lays the ticks in a column or a row, `side` puts the card on either side, and `renderPreview` draws your own card content. Items with an `href` are links; the rest are buttons, with `value` and `onValueChange`.
- **Touch and keyboard.** A finger scrubs along the rail and lifting follows the lit section. Tab shows each card, Escape hides it, and every tick is named for screen readers, with `aria-current` on the current one.
- **React Native.** The same API and motion: a scrub with a tick on every step, and a card that glides on the UI thread.

### Theme Toggle

Theme Toggle is a new button that switches between light and dark. Its sun and moon rotate, scale and crossfade into each other through a small blur, and it follows the density, focus ring, press feedback and motion speed like any other Button.

- **Eight reveals.** On the web and desktop, the new theme can sweep across the page as a rectangle, circle, blurred circle, blinds, square, diamond, hexagon or triangle. Reveals start at the button, or at one of six points on the screen. The blurred circle sharpens the new page from an 8px blur as it grows, and the shapes soften their moving edge while the page stays sharp.
- **Safe fallbacks.** With reduced motion or motion off, the theme changes at once. Browsers without View Transitions still switch the theme.
- **Your theme provider.** Pass the current theme and a change callback, so storing the theme stays with your provider.

```bash
npx fabricator-ui@latest add theme-toggle
```

The docs show every reveal, origin, Button variant and size, and a disabled toggle.

## Updated components

### Date Picker

Date Picker takes a `granularity`: `"day"` (the default), `"month"` or `"year"`. A month or a year opens a grid of twelve instead of the calendar, with the gliding highlight, the sliding selection and a page that slides in from the side it came from. It works as a button field or, with `editable`, as a text field that reads `Mar 2028`, `3/2028`, `2028-03` and `next month`, or `2028` and `next year`. The value is a `Date` on the first day of the month or year, and a form gets `yyyy-MM` or `yyyy`. On the web and on React Native.

### Accordion

Accordion items now sit on a tinted tile, so they stand off the page and off cards in light and dark. Closed items join into one card; an open item parts from its neighbours, rounds its corners and springs open. Trigger labels are 14px in foreground at 80%, and a leading icon rests in grey.

The spring is a new motion role, `bounce`, with `ease-bounce`, `duration-bounce` and the `motion-bounce` utility. Each speed sets how far it overshoots: about 7% at default, peaking at 40% of its 600ms, none at instant. The chevron turns without overshoot and a closing gap settles without dipping into an overlap. The website draws it as a CSS `linear()` curve and React Native interpolates the same samples, so both bounce alike. Reduced motion opens at once and keeps the text fade.

The API is unchanged on Base UI, Radix, React Aria and React Native. Update with `npx fabricator-ui@latest add accordion`.

### Checkbox

Checking a Checkbox now draws its mark in from the short leg while it fades and grows from 0.6. Unchecking shrinks it back through a small blur and fades it out, quicker than it came in. Indeterminate draws a minus instead of a check, and moving between checked and indeterminate retracts one stroke while the other draws. Every timing follows the motion speed, and reduced motion turns the transitions off.

The mark is drawn inline on every base, so it no longer comes from the project's icon library. React Native draws the same strokes with `react-native-svg` on the same timings, without the blur.

### Radio Group

A checked radio is now a primary ring around an 8px primary dot, with a clear inside, instead of a filled circle. Picking another radio glides that one dot over from the radio it leaves, so the selection reads as a single thing moving. A pick made mid-glide turns the dot around from where it is. The first pick scales the dot in. Invalid radios draw the ring and dot in the destructive role.

The glide follows the motion speed, and reduced motion turns it off. It works the same on Base UI, Radix and React Aria, and React Native glides the same dot with Reanimated. The Radio Group now installs the small `radio-glide` item alongside it.

### Slider

- **Step dots.** `showSteps` draws a dot on every value the thumb can land on. The dots under the range shrink away as it covers them, so they count what's left.
- **Sizes.** `size="sm"` and `size="lg"` set the compact and spacious density, like the other controls.
- **A larger thumb.** At the default and large sizes the thumb is bigger than the track: 20px over a 16px track at the default density. At the small size it sits inside the track.
- **Better motion.** A click on the track or a key press glides the thumb and the range to the new value. A drag follows the pointer with no delay. Held, the thumb grows and lifts. All of it follows the motion speed.
- On the web and on React Native.

## Breaking changes

Month Input is gone. Replace `<MonthInput />` with `<DatePicker granularity="month" editable />`. Its `"yyyy-MM"` string values become `Date`s: `value="2028-03"` is `value={new Date(2028, 2, 1)}`, and `minMonth` and `maxMonth` are `minDate` and `maxDate`. `pickerLabel` is `calendarLabel`. A form still receives `yyyy-MM`. Run `npx fabricator-ui@latest add date-picker` and delete `components/ui/month-input.tsx` and `lib/month-input-model.ts`.

## Fixes

- **Multi Select.** Removing several Multi Select chips before their animations finish now removes every chip. Picking a chip again cancels its pending removal. The fix applies to Base UI, Radix and React Aria.

## Docs

Advanced is a new component group for the large, self-contained components. It holds Syntax Highlight, Editor, File Tree, Image Compare, Video Player and Audio Player, which move over from Content, Forms and Structure.

You'll find it after Chat in the docs sidebar, the homepage filter and the desktop and mobile examples. Links, registry names and install commands stay the same, and saved navigation preferences still apply.

---
title: Advanced component group
description: Syntax Highlight, Editor, File Tree, Image Compare, Video Player and Audio Player move into a new Advanced group.
date: 2026-11-12
---

Advanced is a new component group for the large, self-contained components. It holds Syntax Highlight, Editor, File Tree, Image Compare, Video Player and Audio Player, which move over from Content, Forms and Structure.

You'll find it after Chat in the docs sidebar, the homepage filter and the desktop and mobile examples. Links, registry names and install commands stay the same, and saved navigation preferences still apply.

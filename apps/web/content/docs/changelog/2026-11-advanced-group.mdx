---
title: November 2026 - Advanced component group
description: A new Advanced group for the large, self-contained components.
date: 2026-11-12
---

A new component group, Advanced, follows Chat in the documentation, the homepage filter, the desktop example and the mobile example.

It holds Syntax Highlight, Rich Text Editor, File Tree, Image Compare, Video Player and Audio Player, which move from Content, Forms and Structure. Their links, registry names and install commands are unchanged, and saved navigation preferences still apply.

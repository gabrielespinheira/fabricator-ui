---
title: November 2026 - Chat Input and Model Picker on React Native
description: The AI & Chat group is complete on React Native. Chat Input and Model Picker come to phones and tablets, and Questionnaire takes the website's design.
date: 2026-11-10
---

- **Chat Input on React Native.** The same pill that stacks once the draft wraps, or a large card, with one send slot that offers voice while the draft is empty, sends, and stops a reply. Attachments, tinted mentions, the `/` menu, options, trays and the context meter come with it. Return sends, or adds a line with `submitOn="mod-enter"`, and `sticky` rides the keyboard. File drops and pasted files stay on the web, and voice draws its own glow from `voiceLevel`.
- **Model Picker on React Native.** The effort slider takes a tap or a drag, previews each level it crosses and warms from blue to violet. The routes, the models grouped by provider and the settings come with it, in a popover or a sheet of your own.
- **Questionnaire takes the website's design on React Native.** Choices are rows with a chip at the end, the letter or number for a single choice and a square that fills for a multiple one, and a chosen row holds the active fill. `QuestionnaireHeader` and `advanceOnSelect` come too, so the questions can take a chat input's place.
- **One model for both platforms.** Chat Input's and Model Picker's rules, such as what the send slot does, when the pill stacks and where the effort thumb sits, now live in shared modules the website and React Native both import.

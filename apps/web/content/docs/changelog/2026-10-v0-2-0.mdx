title: October 2026 - Version 0.2.0
description: The Fabricator design system, Fluid Hover, sounds, a pill radius, Search, a new Sidebar and a redesigned website.
date: 2026-10-09
---

Version 0.2.0 of the `fabricator-ui` CLI and the registry brings the full Fabricator design language.

- **Design system:** surfaces, interaction tokens, motion tiers, scrollbars and a new look for every component. See [Foundations](/docs/foundations/surfaces).
- **Fluid Hover:** one gliding highlight across menus, select, combobox, command, tabs, sidebar, accordion and table, in all three bases.
- **Sounds, pill radius and surface tint:** `@fabricator/sounds`, `@fabricator/radius-pill`, and a base colour that tints every surface.
- **Search and Sidebar:** a new Search component, and a Sidebar that resizes, peeks and collapses its sections.
- **Checkbox and radio:** redesigned, with a fixed selected-day hover in Calendar.
- **Removed:** Native Select and Chart are left out of Fabricator mode, and RTL support is dropped. Blend mode still ships every upstream item.

Update an existing project with:

```bash
npx fabricator-ui@latest add foundations
```

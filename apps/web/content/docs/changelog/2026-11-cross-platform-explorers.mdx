---
title: November 2026 - Cross-platform explorers and native components
description: Icons in the desktop and mobile examples, shared component navigation, and the remaining native component demos.
date: 2026-11-10
---

- The desktop and mobile examples have an Icons page with search, outline, brand and file icons, size controls, and import commands. Animated icons are available on the web.
- The documentation uses the App Shell, with the same component groups and homepage settings as the examples. Desktop component pages show the documented variants and properties.
- Color Picker, File Tree, File Upload, Number Field, Time Input and Time Wheel are available in the native registry. Data Table, Typography and Fabricator Root also have native demos.
- Native File Upload accepts URI-based assets. Supply document picking through `FileUploadPickerProvider` or `onPick`; the browse action stays disabled until a picker is supplied.
- Native registry coverage now includes every published web component. Browser-only interactions, such as drag-and-drop uploads and the eyedropper, have documented native differences.

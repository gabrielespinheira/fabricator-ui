---
title: React Native differences
description: What each React Native component does differently from its web version, and why.
---

Native components keep the web component's name, exports, variants, sizes and tokens, with the differences listed below. Components listed as not yet available have explicit, dated deferrals in the parity check.

Across all of them: `onPress` replaces `onClick`, `hover:` styles become `active:`, and text goes through `Text`, since React Native has no cascade. A screen written for the web won't run on native unchanged, because `<div>` and `<span>` don't exist there.

- **Same**: the same use.
- **Touch input**: the same API, with a touch gesture in place of a web input.
- **New engine**: the same API, with a DOM-only library replaced underneath.
- **Kept for imports**: exists so code compiles, and does nothing.

Interface sounds are the same on React Native, under the same `<SoundEffects />`, with a haptic for each. The ring switch silences them.

## Not yet available

These web components are not available for React Native yet. Each deferral has a reason and date in the parity exceptions.

- **Chat Input** (2026-11-09): Web-first chat composer uses DOM text editing, file drop/paste and voice-glow. Native composition, attachment picking and voice visuals are deferred.
- **Color Picker** (2026-11-09): Web-first color picker uses pointer scrubbing and the browser eyedropper. Native touch color controls are deferred.
- **File Tree** (2026-11-09): Desktop explorer ships on web first. Native touch selection and action menus are deferred.
- **File Upload** (2026-11-09): Web-first upload controls use File, drag-and-drop, paste and native HTML form submission. Native document/image picking is deferred.
- **Model Picker** (2026-11-09): Web-first model and reasoning selector ships with Chat Input. Native selector presentation is deferred with the composer.
- **Number Field** (2026-11-09): Web Number Field ships first. Native number formatting models exist, but the native stepper field and its demo are deferred.
- **Time Input** (2026-11-09): Web-first time field and duration modes use Time Wheel. Native field and wheel controls are deferred; the native Date Picker documents this limit.
- **Time Wheel** (2026-11-09): Web-first wheel is a Time Input and Date Picker part. Native touch scrolling, snapping and accessibility adjustments are deferred with Time Input.

There is no slash menu: formatting comes from the toolbar, the keyboard bar, Markdown shortcuts and a hardware keyboard's shortcuts. The link editor is a dialog. Tables draw as the Markdown preview's grid in the text view and edit in a sheet on phones and tablets (a tap on the table opens it): a grid of cell fields, rows and columns added and removed at the focused cell, the focused column's alignment, Cancel and Done, where the website edits them in place. Code blocks wrap their lines instead of scrolling sideways (one text view can't scroll a paragraph on its own); their language and Copy are drawn in the block's strip, and a tap on the language opens a sheet to pick another. While the editor has focus, `EditorKeyboardBar` takes the bottom of the screen from the App Shell's tab bar (through the `bottom-bar` slot): a floating capsule in the tab bar's place, docked full width on top of the on-screen keyboard while that's up, with Done giving the tab bar back. It needs `KeyboardProvider` from `react-native-keyboard-controller` at the app's root. |

## Installation

```bash
npx fabricator-ui@latest add sounds
```

This adds `lib/sounds.ts`, the sound engine, and `components/sound-effects.tsx`, which plays sounds for every component. There are no audio files and no dependencies: each sound is a few milliseconds of oscillators and filtered noise, made with the Web Audio API when it plays.

## The catalogue

Fifteen sounds, each made for one kind of moment. Press one to hear it.

## Set up

Render `<SoundEffects />` once, near the root of your app, and pass it the user's preference:

```tsx title="components/providers.tsx"
"use client"

import { SoundEffects } from "@/components/sound-effects"

export function Providers({
  soundsOn,
  children,
}: {
  soundsOn: boolean // the user's setting, however you store it
  children: React.ReactNode
}) {
  return (
    <>
      <SoundEffects enabled={soundsOn} />
      {children}
    </>
  )
}
```

Sounds are off until `enabled` is `true`, or until you call `setSoundsEnabled(true)`. Nothing in the components changes: `<SoundEffects />` listens on the document and picks a sound from the control's role and `data-slot`, which are the same in every base.

## What plays when

| Interaction                                                            | Sound                      |
| ---------------------------------------------------------------------- | -------------------------- |
| Button, menu item, button link                                         | `tap`                      |
| Tab, radio, option, menu radio, toggle group item, pressed toggle      | `tick`                     |
| Checkbox, menu checkbox                                                | `check` / `uncheck`        |
| Switch                                                                 | `toggle-on` / `toggle-off` |
| Dialog, alert dialog, sheet, drawer                                    | `open`, then `close`       |
| Popover, dropdown, context menu, menubar, select, combobox, hover card | `pop`                      |
| Toast                                                                  | `notify`                   |
| Slider step                                                            | `notch`                    |
| A control with `aria-disabled="true"`                                  | `deny`                     |

Triggers that open a popup stay quiet, so opening a menu plays one `pop` rather than a tap and a pop. Tooltips never play: they appear too often.

## Choose a sound

Set `data-sound` on any element to choose its sound, or `data-sound="none"` to silence it and everything inside it:

```tsx
<Button data-sound="copy" onClick={copyLink}>
  Copy link
</Button>

<section data-sound="none">{/* a quiet area */}</section>
```

## Play sounds yourself

```tsx
import { playSound, useSound, useSoundsEnabled } from "@/lib/sounds"

// Anywhere: plays only when sounds are on.
playSound("success")

// In a component: a stable callback.
const playNotify = useSound("notify")

// A settings toggle.
const [enabled, setEnabled] = useSoundsEnabled()
```

| Function                    | Description                                                                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `playSound(name, options?)` | Plays a sound. `volume` (0 to 1) and `pitch` (a multiplier) adjust one play; `force` plays it even when sounds are off, for previews. |
| `useSound(name, options?)`  | A stable callback that plays the sound.                                                                                               |
| `setSoundsEnabled(enabled)` | Turns sounds on or off. They start off.                                                                                               |
| `useSoundsEnabled()`        | `[enabled, setEnabled]`, kept in sync everywhere.                                                                                     |
| `setSoundVolume(volume)`    | The master volume, 0 to 1 (0.6 by default).                                                                                           |
| `SOUNDS`                    | The catalogue: name, category, description, length and pitch.                                                                         |

The same sound can't repeat within 35ms, and no more than six play at once, so a fast drag or a burst of events stays quiet.

## Accessibility

- Sounds start off. Give people a visible switch, and remember their choice.
- Sound is never the only feedback: every interaction that plays one also changes on screen.
- Nothing plays while the tab is hidden, and the audio engine only starts after someone interacts with the page, as browsers require.

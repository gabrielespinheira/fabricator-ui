# Brand marks

The brand marks in this package are trademarks of their owners. Including them
here does not imply any affiliation with, or endorsement by, those owners.

The package's MIT licence covers Fabricator's code, not the marks. Before you
use a mark, read its owner's brand guidelines, linked below where known, and
use it only to refer to that brand or its product.

Geometry is reproduced as the sources publish it. The only changes are a
uniform scale through the viewBox, so every mark sits at the same optical
size, and the colour you render it in.

To ask for a mark to be removed or updated, open an issue at
https://github.com/gabrielespinheira/fabricator-ui/issues. Removals ship in the
next patch release.

## Held

These marks are not included, because their owners' terms don't allow
redistributing them in a library like this one.

| Brand | Why |
| --- | --- |
| Amazon Web Services | AWS licenses its logos only to customers and partners for specific uses, and fair use is plain text only (https://aws.amazon.com/trademark-guidelines/). |
| Microsoft | Microsoft licenses its logos to third parties only by formal agreement (https://learn.microsoft.com/en-us/windows/apps/publish/partner-center/trademark-and-copyright-protection). |
| OpenAI | OpenAI's usage terms make its logo permission non-transferable (https://openai.com/brand/#usage-terms), and Simple Icons removed this older mark at OpenAI's request. Held until OpenAI grants redistribution. |
| Slack | Slack's brand terms forbid distributing its logo files (https://slack.com/terms-of-service/slack-brand). |
| Visual Studio Code | Microsoft forbids modified versions of the VS Code icon, which a one-colour mark is (https://code.visualstudio.com/brand). |
